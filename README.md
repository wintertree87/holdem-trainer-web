# 🃏 텍사스 홀덤 트레이너

포커 프리플랍과 포스트플랍 전략을 연습할 수 있는 인터랙티브 트레이너입니다.

## 🎯 기능

### 게임 모드
- **RFI (Raise First In)**: 첫 번째로 레이즈하는 상황 연습
- **Facing RFI**: 상대의 오픈에 대응하는 연습
- **vs 3bet**: 3bet을 받았을 때 대응 연습
- **C-bet**: 플랍에서 컨티뉴에이션 벳 연습

### 주요 기능
- ✅ PokerCoaching 차트 기반 정확한 레인지
- 🪑 9인 테이블 포지션 시각화
- 📊 실시간 정답률 추적
- 📖 초보자를 위한 용어사전
- ⌨️ 키보드 단축키 지원
- 📱 모바일 반응형 디자인

## 🚀 사용 방법

1. [여기](https://USERNAME.github.io/holdem-trainer-web/)에서 바로 플레이
2. 모드를 선택하고 포지션을 설정
3. 핸드를 보고 올바른 액션을 선택
4. 정답 확인 및 학습

## ⌨️ 키보드 단축키

- `R` - 레이즈
- `C` - 콜
- `F` - 폴드
- `3` - 3bet
- `4` - 4bet
- `B` - C-bet
- `X` - 체크
- `Space` - 다음 핸드
