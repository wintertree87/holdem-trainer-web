## Level 1 (1-4주): 프리플랍 기초 — "올바른 핸드만 플레이하기"

### 학습 목표
- 어떤 핸드가 강하고 약한지 직관적으로 판단할 수 있다
- 포지션에 따라 오픈 레인지를 달리해야 하는 이유를 안다
- RFI 레인지를 80% 이상 정확도로 맞출 수 있다

### 핵심 개념

#### 1. 핸드 랭킹 이해
- **프리미엄**: AA, KK, QQ, JJ, AKs — 어디서든 강하다
- **브로드웨이**: AQ, AJ, KQ, KJ, QJ 등 — T 이상 카드 2장 조합
- **미들/스몰 포켓페어**: 99-22 — 셋 맞으면 대박, 안 맞으면 어려움
- **수티드 커넥터**: 76s, 87s, 98s — 스트레이트+플러시 가능성, 포지션 좋을 때만
- **수티드 에이스**: A5s, A4s, A3s — 넛 플러시 가능성, 블러프 3벳 후보

#### 2. 포지션의 중요성
```
초반 (EP): UTG, UTG+1, UTG+2 — 뒤에 7-8명 남음 → 타이트하게
중반 (MP): LJ, HJ — 뒤에 4-5명 → 약간 넓게
후반 (LP): CO, BTN — 뒤에 2-3명 → 넓게
블라인드: SB, BB — 강제 베팅 + OOP → 특별한 전략
```

**왜 BTN이 최고의 포지션인가?**
- 뒤에 2명(블라인드)만 남아서 오픈 레인지 넓음 (51%)
- 포스트플랍에서 항상 마지막에 행동 (정보 우위)

**왜 UTG가 힘든가?**
- 뒤에 8명이 남아서 누군가 강한 핸드 가질 확률 높음
- 오픈 레인지 좁음 (10%)

#### 3. RFI (Raise First In) 레인지
나한테 액션이 왔을 때 아무도 레이즈 안 했으면, 포지션별로 정해진 핸드만 오픈한다.

| 포지션 | 오픈 비율 | 대표 핸드 |
|--------|----------|----------|
| UTG | 10.1% | AA-77, AKs-ATs, KQs, AKo |
| UTG+1 | 14.3% | +66, A9s, KJs, AQo |
| UTG+2 | 16.1% | +A8s, QJs, KJo |
| LJ | 19.0% | +55, A5s-A4s, JTs, KQo |
| HJ | 22.1% | +A3s-A2s, T9s, QJo |
| CO | 30.3% | +44-33, K9s, Q9s, KTo |
| BTN | 51.1% | +22, 광범위한 수티드/오프수트 |
| SB | Value 8.9% + Bluff 13% + Limp 48.6% | 특별 전략 |

#### 4. 팟 오즈 기초
- 팟에 100이 있고, 콜해야 할 금액이 50이면 → 팟 오즈 = 50/(100+50) = 33%
- 내 핸드가 이길 확률이 33% 이상이면 콜이 수학적으로 이득
- **"콜할 때는 항상 팟 오즈를 생각하자"**

## Level 2 (5-8주): 프리플랍 심화 — "상대 액션에 대응하기"

### 학습 목표
- 상대가 오픈했을 때 3벳/콜/폴드 판단을 할 수 있다
- 내가 오픈한 후 3벳 받았을 때 대응할 수 있다
- BB 디펜스 개념을 이해한다

### 핵심 개념

#### 1. 3벳 전략
- **밸류 3벳**: AA, KK, QQ, AKs 등 강한 핸드로 팟 키우기
- **블러프 3벳**: A5s, A4s 등 블로커+플러시 가능성 있는 핸드로 3벳
- **왜 블러프 3벳을 하나?**: 3벳이 전부 강한 핸드면 상대가 쉽게 폴드. 블러프를 섞어야 착취당하지 않음

#### 2. Facing RFI 대응
상대가 오픈했을 때 나의 포지션과 상대 포지션에 따라:
- **3벳**: 강한 핸드 or 선별된 블러프
- **콜**: 중간 강도 핸드 (셋이나 스트레이트 노리기)
- **폴드**: 나머지

원칙: 오프너의 포지션이 빠를수록(UTG 등) 더 타이트하게 대응

#### 3. vs 3벳 대응
내가 오픈한 후 3벳을 받았을 때:
- **4벳**: AA, KK + 블러프 (AKo, A5s 등)
- **콜**: QQ, JJ, AQs 등 중간 핸드
- **폴드**: 나머지 약한 핸드

#### 4. BB 디펜스
BB는 이미 1BB 투자한 상태이므로 팟 오즈가 유리 → 많은 핸드로 디펜스

## Level 3 (9-12주): 포스트플랍 기초 — "플랍에서 올바른 판단하기"

### 학습 목표
- 보드 텍스쳐를 읽고 유불리를 판단할 수 있다
- C벳 해야 할 상황과 체크해야 할 상황을 구분할 수 있다
- 핸드 스트렝스를 빠르게 평가할 수 있다

### 핵심 개념

#### 1. 보드 텍스쳐 읽기
```
드라이 보드: K♠ 7♦ 2♣ — 드로우 없음, 메이드핸드 유리
웻 보드: J♥ T♥ 9♠ — 스트레이트+플러시 드로우 많음, 위험
모노톤: Q♥ 8♥ 3♥ — 같은 수트 3장, 플러시 완성 가능
페어드: K♠ K♦ 5♣ — 보드에 페어, 풀하우스/트립스 가능
```

#### 2. C벳 전략
- **C벳 = 프리플랍 레이저가 플랍에서 하는 첫 베팅**
- 드라이 보드 → C벳 유리 (상대 핸드가 맞기 어려움)
- 웻 보드 → C벳 주의 (상대가 다양한 드로우 보유)
- 강한 핸드 → 밸류 C벳 (돈 더 넣기)
- 약한 핸드 + 드라이 보드 → 블러프 C벳 (상대 폴드 유도)

#### 3. 핸드 스트렝스 카테고리
| 카테고리 | 예시 | 강도 |
|---------|------|------|
| 오버페어 | QQ on J-7-2 보드 | 매우 강 |
| 탑페어 탑키커 (TPTK) | AK on K-8-3 보드 | 강 |
| 탑페어 약한 키커 | K7 on K-8-3 보드 | 중 |
| 미들 페어 | 88 on K-8-3 보드 | 중약 |
| 언더페어 | 77 on K-8-3 보드 | 약 |
| 드로우 | 9♥8♥ on J♥7♥2♣ | 가능성 |
| 에어 | 65 on K-Q-3 보드 | 매우 약 |

#### 4. IP vs OOP
- **IP (In Position)**: 상대 뒤에 행동 → C벳 더 자유롭게
- **OOP (Out of Position)**: 먼저 행동 → 더 신중하게

## Level 4 (13-20주): 포스트플랍 심화 — "턴과 리버까지"

### 학습 목표
- 플랍-턴-리버를 관통하는 일관된 전략 수립
- 벳 사이징 선택 근거를 설명할 수 있다
- 블러프캐칭과 씬밸류벳 상황을 판단할 수 있다

### 핵심 개념

#### 1. 멀티스트릿 플래닝
- 플랍에서 베팅할 때 이미 턴과 리버 계획까지 생각
- "이 핸드로 3스트릿 밸류가 나오나?" 질문하기
- 강한 핸드 → 3스트릿 밸류 (플랍-턴-리버 계속 베팅)
- 중간 핸드 → 1-2스트릿 밸류 (어느 시점에 체크)

#### 2. 벳 사이징
| 사이즈 | 언제 사용 | 효과 |
|--------|----------|------|
| 1/3 팟 | 드라이 보드 C벳, 씬밸류 | 저렴하게 정보 획득 |
| 1/2 팟 | 기본 밸류벳 | 균형잡힌 사이즈 |
| 3/4 팟 | 밸류 + 보호 필요 | 드로우에게 비싼 가격 |
| 풀팟+ | 강한 밸류 or 극단 블러프 | 상대에게 어려운 결정 |

#### 3. 체크레이즈
- OOP에서 강한 핸드를 체크 → 상대 베팅 → 레이즈
- 강한 핸드와 블러프를 섞어서 구성

#### 4. 블러프캐칭
- 상대 레인지에 블러프가 충분히 있을 때, 미디엄 핸드로 콜
- "상대가 여기서 블러프하는 핸드가 있나?" 질문

#### 5. 씬밸류벳
- 더 약한 핸드가 콜할 수 있을 때, 마지날 핸드로 작은 밸류벳

## Level 5 (21주+): 실전 최적화 — "홈게임/펍에서 이기기"

### 학습 목표
- 상대 유형을 파악하고 그에 맞게 전략 조정
- GTO에서 벗어나 익스플로잇 전략 구사
- 멀티웨이 팟에서 적절히 조정
- 감정 관리와 뱅크롤 관리

### 핵심 개념

#### 1. 상대 유형 파악
| 유형 | 특징 | 익스플로잇 |
|------|------|-----------|
| 타이트-패시브 (니트) | 좋은 핸드만, 수동적 | 많이 스틸, 그가 베팅하면 폴드 |
| 루즈-패시브 (피쉬) | 많은 핸드 참여, 콜링 스테이션 | 밸류벳 크게, 블러프 줄이기 |
| 타이트-어그레시브 (TAG) | 선별적, 공격적 | 3벳 자주, 포스트플랍 주의 |
| 루즈-어그레시브 (LAG) | 많은 핸드, 공격적 | 트랩, 강한 핸드 슬로우플레이 |

#### 2. 홈게임/펍 특화 전략
- 대부분 상대는 루즈-패시브 → 밸류벳 위주, 블러프 줄이기
- 라이브 텔(tells) 관찰: 베팅 패턴, 칩 다루기, 대화
- 멀티웨이 팟이 많음 → 레인지 타이트하게 조정
- 포지션 가치가 더 중요 (라이브에서 OOP 실수 많음)

#### 3. 뱅크롤 관리
- 한 세션 바이인 = 전체 뱅크롤의 5% 이하
- 연패해도 스테이크 올리지 않기 (틸트 방지)
- 이겼을 때 적절한 시점에 자리 뜨기

#### 4. 멘탈 게임
- 배드빗은 장기적으로 평균 회귀
- 결과보다 의사결정 품질에 집중
- 틸트 감지 → 즉시 세션 종료 or 휴식
