# PRD: 홀덤 트레이너 v2

## 한 줄 정의
홀덤 입문자가 **듀오링고처럼 매일 5분씩** 프리플랍~포스트플랍 기초를 체계적으로 마스터하는 웹앱

---

## 왜 다시 쓰는가

### 현재 제품의 문제
지금 홀덤 트레이너는 **퀴즈 앱**이다.
- 4개 모드(RFI, Facing RFI, vs 3bet, C-bet)를 고르면 랜덤으로 핸드가 나온다
- 학습 순서가 없다 — 입문자가 RFI도 모르는데 C-bet 모드를 열 수 있다
- 성장을 못 느낀다 — "내가 뭘 얼마나 배웠지?"에 대한 답이 없다
- 중독 루프가 없다 — 한 번 써보고 다시 올 이유가 부족하다

### 목표하는 제품
**학습 앱**으로 바꾼다.
- 듀오링고처럼 **레슨 → 유닛 → 스킬 트리** 구조
- 쉬운 것부터 어려운 것까지 **점진적 난이도 상승**
- 매일 돌아오게 만드는 **게이미피케이션** (XP, 크라운, 스트릭)
- 최종 목표: **홀덤 중수**(프리플랍 마스터 + 포스트플랍 기초)까지 도달

### 핵심 전환
```
[지금]  모드 선택 → 랜덤 출제 → 정답/오답
[목표]  스킬 트리 → 가이드 → 레슨 → 피드백 → 보상 → 다음 레슨
```

---

## 타겟 유저

### Primary: 홀덤 입문자
- **누구**: 룰은 아는데 "이 핸드 어떻게 해?"가 막히는 사람
- **상황**: 홈게임/홀덤펍에서 매번 돈을 잃고, 뭘 잘못하는지도 모름
- **원하는 것**: "이 자리에서 이 패면 이렇게 해" 라는 확신
- **사용 시나리오**: 출퇴근 지하철 5분, 홀덤펍 가기 전 워밍업, 자기 전 3레슨

### Secondary: 프리플랍은 되는데 포스트플랍이 약한 사람
- 오픈 레인지는 외웠는데 플랍 나오면 멘붕
- 보드 읽기, C벳 판단, 핸드 강도 평가를 연습하고 싶음

## 제품 비전: "홀덤의 듀오링고"

### 듀오링고에서 가져오는 5가지 원리

| 원리 | 듀오링고 | 홀덤 트레이너 |
|------|---------|-------------|
| **스킬 트리** | 언어 → 토픽 → 레슨 순서대로 | 포커 → 유닛 → 레슨 순서대로 |
| **짧은 레슨** | 5분에 끝나는 한 레슨 | 10~15핸드, 3~5분 |
| **즉각 피드백** | 맞으면 초록, 틀리면 빨강 + 설명 | 정답/오답 + "왜 틀렸는지" |
| **보상 루프** | XP, 레벨, 크라운, 스트릭 | XP, 레벨, 크라운, 스트릭 |
| **점진적 난이도** | A→B→C... 쉬운 단어부터 | AA 레이즈 → A9s UTG 폴드 → A5s 블러프 3벳 |

### 학습 설계 원칙
1. **한 번에 한 가지만** — 레슨 하나는 하나의 개념
2. **쉬운 것부터** — AA 레이즈부터 시작, 경계선 케이스로 점진 이동
3. **실수에서 배운다** — 오답 설명의 질이 제품의 질
4. **체감 가능한 성장** — XP, 레벨, 정확도 차트로 "나 늘고 있다"를 느끼게
5. **중독 루프** — 레슨 완료 → 보상 → 다음 레슨 호기심 → 반복

## 스킬 트리: 12개 유닛

홀덤 중수까지의 여정을 12개 유닛으로 나눈다. 이전 유닛을 통과해야 다음 유닛이 잠금 해제된다.

```
[기초 파트] ─────────────────────────────────
│
├─ Unit 1: 핸드의 세계          "카드 읽기부터 시작"
│  ├─ 1-1. 카드 읽기 (AKs, QJo 표기법)
│  ├─ 1-2. 핸드 계급 (AA > KK > ... > 72o)
│  ├─ 1-3. 핸드 카테고리 (프리미엄/브로드웨이/SC/수티드에이스)
│  └─ 1-4. 수티드의 힘 (같은 무늬가 왜 중요한가)
│
├─ Unit 2: 자리가 돈이다        "포지션이 전략을 바꾼다"
│  ├─ 2-1. 포지션 이름 (UTG~BB 9개 자리)
│  ├─ 2-2. 포지션과 레인지 (UTG 10% → BTN 51%)
│  └─ 2-3. IP vs OOP (정보 우위의 핵심)
│
[프리플랍 마스터] ───────────────────────────
│
├─ Unit 3: 첫 번째 공격         "RFI: 레이즈 or 폴드"
│  ├─ 3-1. RFI란? (첫 레이즈 개념 + 쉬운 핸드)
│  ├─ 3-2. UTG 레인지 (가장 타이트한 10%)
│  └─ 3-3. EP 확장 (UTG+1, UTG+2)
│
├─ Unit 4: 넓혀가기             "포지션별 RFI 완성"
│  ├─ 4-1. LJ/HJ 오픈 (19~22%)
│  ├─ 4-2. CO 오픈 (30%)
│  ├─ 4-3. BTN 오픈 (51%)
│  └─ 4-4. EP vs LP 비교 드릴 (같은 핸드, 다른 결정)
│
├─ Unit 5: 특수 작전            "블라인드 전략"
│  ├─ 5-1. SB 전략 (레이즈/림프/폴드)
│  └─ 5-2. BB 디펜스 (이미 투자한 돈의 힘)
│
├─ Unit 6: 반격                 "3벳/콜/폴드"
│  ├─ 6-1. 3벳 기초 (상대 오픈에 리레이즈)
│  ├─ 6-2. 밸류 vs 블러프 3벳 (A5s가 A9o보다 나은 이유)
│  └─ 6-3. 오프너 포지션별 대응 (UTG오픈 vs CO오픈)
│
├─ Unit 7: 재반격               "vs 3bet 대응"
│  └─ 7-1. 3벳 받았을 때 (4벳/콜/폴드)
│
├─ Unit 8: 숫자의 힘            "팟 오즈 기초"
│  ├─ 8-1. 팟 오즈 계산 (콜 판단의 수학)
│  └─ 8-2. 드로우 판단 (아웃 × 2, × 4)
│
[포스트플랍 입문] ──────────────────────────
│
├─ Unit 9: 전장 읽기            "보드 텍스쳐"
│  ├─ 9-1. 드라이 vs 웻 (3초 안에 판단)
│  └─ 9-2. 모노톤과 페어드 (특수 보드)
│
├─ Unit 10: 공격 유지           "C벳 전략"
│  ├─ 10-1. C벳 기초 (언제 쏘고 언제 체크)
│  └─ 10-2. 보드별 C벳 (드라이 vs 웻 전략 차이)
│
├─ Unit 11: 핸드 강도 판관      "플랍 후 내 패 평가"
│  └─ 11-1. 핸드 카테고리 분류 (오버페어~에어)
│
└─ Unit 12: 돈의 언어           "벳 사이징"
   └─ 12-1. 사이즈 선택 (1/3, 1/2, 3/4 언제?)
```

## 레슨 구조

### 레슨 흐름

```
[가이드 카드]          ← 30초. 이번 레슨에서 배울 개념 2~3문장 설명
    ↓
[퀴즈 10~15핸드]      ← 3~5분. 핸드별 즉각 피드백
    ↓                    틀리면 → 왜 틀렸는지 + 올바른 답 설명
    ↓                    맞으면 → 초록색 + 격려 메시지
    ↓                    하트 0 → 레슨 실패, 재시도
    ↓
[결과 화면]            ← 정답률, 획득 XP, 퍼펙트 여부
    ↓
[다음 레슨 잠금해제]   ← 호기심 유발 ("다음: 포지션과 레인지")
```

### 레슨 내 난이도 곡선

```
앞쪽 30%:  ████░░░░░░  쉬움 (워밍업, 자신감 부여)
중간 40%:  ░░░█████░░  보통 (본 학습)
후반 30%:  ░░░░░░░███  어려움 (도전, 경계선 케이스)
```

### 퀴즈 유형

| 유형 | 선택지 | 사용 유닛 |
|------|--------|----------|
| `identify` | 카테고리 식별 | Unit 1, 2, 13 |
| `binary` | 레이즈/폴드 | Unit 3, 4 |
| `ternary` | 3벳/콜/폴드 | Unit 5, 6, 7 |
| `position` | 비율 선택 | Unit 2 |
| `board_read` | 드라이/웻 | Unit 9 |
| `strength` | 강/중/약 | Unit 11 |
| `sizing` | 1/3, 1/2, 3/4 | Unit 12 |

## 게이미피케이션

### XP (경험치)
매일의 성장을 숫자로 보여준다.

```
정답 1개:          +10 XP
레슨 완료:         +20 XP
퍼펙트 레슨(0오답): +50 XP
일일 목표 달성:     +30 XP
유닛 잠금 해제:    +100 XP
```

### 레벨
XP 누적 → 레벨 업. 칭호가 바뀐다.

| 레벨 | 누적 XP | 칭호 | 대략 도달 시점 |
|------|---------|------|-------------|
| 1 | 0 | 루키 | 시작 |
| 2 | 200 | 비기너 | 1~2일 |
| 3 | 500 | 러너 | 3~5일 |
| 4 | 1,000 | 플레이어 | 1~2주 |
| 5 | 2,000 | 레귤러 | 3~4주 |
| 6 | 4,000 | 그라인더 | 5~6주 |
| 7 | 7,000 | 솔리드 | 7~8주 |
| 8 | 12,000 | 프로피셔너 | 10주+ |
| 9 | 20,000 | 샤크 | 마스터 반복 후 |
| 10 | 35,000 | 위저드 | 장기 플레이어 |

### 크라운 (숙련도)
같은 레슨을 반복하면 크라운이 올라간다. 크라운이 높을수록 어려운 문제가 나온다.

```
Crown 0: 잠김
Crown 1: 1회 완료, 정답률 50%+
Crown 2: 2회 완료, 정답률 65%+
Crown 3: 3회 완료, 정답률 75%+
Crown 4: 4회 완료, 정답률 85%+
Crown 5: 5회 완료, 정답률 90%+ (연속 2회) → 마스터!
```

7일 복습 안 하면 크라운 1단계 하락 → 복습 동기 부여

### 스트릭 (연속 학습)
```
매일 1레슨 이상 → 스트릭 유지
건너뛰면 → 리셋
7일: "일주일 전사" 뱃지 + 50 XP
30일: "한 달 그라인더" 뱃지 + 200 XP
```

### 하트 (실수 허용)
```
하트 5개 시작
오답 → 하트 -1
하트 0 → 레슨 실패, 재시도
4시간마다 1개 회복 (최대 5개)
```

## 오답 설명 시스템

오답 시 보여주는 설명이 제품의 핵심 가치. 단순히 "틀렸습니다"가 아니라 **왜 틀렸는지**를 알려준다.

### 설명 패턴

**RFI — 레이즈해야 하는데 폴드한 경우:**
> "{hand}은(는) {position} RFI 레인지({percent})에 포함됩니다.
> {카테고리 이유}. {position}에서는 상위 {percent}를 오픈합니다."
>
> 예: "A5s은(는) UTG 레인지(10.1%)에 포함됩니다.
> 수티드 에이스로 넛 플러시 가능성 + 블로커 가치. UTG에서는 상위 10.1%만 오픈합니다."

**RFI — 폴드해야 하는데 레이즈한 경우:**
> "{hand}은(는) {position} RFI 레인지에 포함되지 않습니다.
> {약점 이유}. {position}에서는 {비슷하지만 더 강한 핸드}까지만 오픈합니다."
>
> 예: "KJo은(는) UTG 레인지에 포함되지 않습니다.
> 오프수트 브로드웨이이지만 UTG에서는 너무 약합니다. KQo까지만 오픈합니다."

**Facing RFI — 3벳 vs 콜 vs 폴드:**
> 밸류 3벳: "강한 핸드로 팟을 키우세요."
> 블러프 3벳: "A블로커 + 플러시 가능성이 핵심."
> 콜: "3벳하기엔 약하지만, 팟 오즈상 콜이 적절합니다."
> 폴드: "{vsPosition}의 레인지를 상대하기엔 너무 약합니다."

## 구현 로드맵

### 현재 상태
- 단일 HTML 파일 (~3376줄)
- 4개 모드 기반 랜덤 퀴즈
- localStorage 저장, 일일 목표, 오답 노트, 학습 모드
- 📚 공략집 뷰어 (초급/중급/고급)

### Phase 1: 스킬 트리 도입 (단일 HTML 유지)

**테마: "퀴즈 앱 → 학습 앱 전환"**

기존 HTML 파일에 스킬 트리 UI와 레슨 시스템을 추가한다. 기존 4개 모드(RFI, Facing RFI, vs 3bet, C-bet)는 "자유 연습" 메뉴로 남긴다.

| 기능 | 설명 | 우선순위 |
|------|------|---------|
| 스킬 트리 화면 | 12유닛을 선형으로 보여주는 메인 화면. 잠금/해제 상태 표시 | P0 |
| 레슨 플로우 | 가이드 카드 → 퀴즈 → 결과 화면 흐름 | P0 |
| 유닛 1~4 시나리오 | knowledge-base의 데이터를 JS 객체로 구현 | P0 |
| 레슨 진행도 저장 | localStorage에 레슨별 완료/크라운 상태 | P0 |
| 정확도 히트맵 | 13x13 차트에 핸드별 정답률 색상 | P1 |
| 스페이스드 레피티션 | 자주 틀리는 핸드 3배 더 출제 | P1 |
| 세션 요약 | 레슨 완료 후 포지션별 정답률 + 약점 핸드 | P1 |

**기술 제약**: 단일 HTML 파일 유지. localStorage만 사용.

### Phase 2: 게이미피케이션 (단일 HTML 유지)

**테마: "매일 돌아오게 만들기"**

| 기능 | 설명 |
|------|------|
| XP + 레벨 | 정답/레슨 완료 시 XP 부여. 레벨 칭호 표시 |

| 유닛 5~8 시나리오 | Facing RFI, vs 3bet, 팟오즈 데이터 추가 |

**테마: "지속 가능한 제품"**

| 구분 | 무료 | 프리미엄 (월 9,900원) |

## 성공 지표

### Phase 1 (출시)
- 자체 사용: 매일 3레슨 이상

- 친구/지인 공유: 5명 이상 사용
- 재방문율: 주 3회 이상
- 평균 스트릭: 5일+

- 가입 유저: 100명
- 주간 활성 유저(WAU): 30명
- 유닛 8(프리플랍 마스터) 도달률: 20%

### Phase 4 (수익화)
- 유료 전환율: 5%
- MRR: 100만원 (유료 유저 ~100명)
- 평균 세션 시간: 8분+
