## 1. EV 사고

### 모든 결정을 숫자로 만들어라

EV(Expected Value, 기대값)는 **어떤 결정을 무한히 반복했을 때, 평균적으로 벌거나 잃는 금액**이다.

좋은 결정 = +EV (장기적으로 돈을 번다)
나쁜 결정 = -EV (장기적으로 돈을 잃는다)

### EV 계산 공식

```
EV = (이길 확률 × 이길 때 따는 금액) - (질 확률 × 질 때 잃는 금액)
```

### 예시: 리버 콜 결정

> 팟 300. 상대 리버 베팅 200. 내 콜 200.
> 상대 레인지 분석: 60% 밸류 핸드(내가 진다), 40% 블러프(내가 이긴다)

```
콜의 EV:
  이길 때: 40% × (300 + 200) = 40% × 500 = 200
  질 때: 60% × 200 = 120

  EV = 200 - 120 = +80

→ 콜이 +EV. 장기적으로 콜할 때마다 평균 80을 번다.
```

### 예시: 블러프 결정

> 팟 400. 리버에서 에어. 블러프 사이즈 300 고려 중.
> 상대가 폴드할 확률 추정: 50%

```
블러프의 EV:
  상대 폴드: 50% × 400 = 200 (팟 획득)
  상대 콜: 50% × (-300) = -150 (블러프 비용)

  EV = 200 - 150 = +50

→ 블러프가 +EV. 상대가 절반 이상 접으면 이득.
```

### 브레이크이븐 포인트

**"상대가 최소 몇 % 접어야 블러프가 이득인가?"**

```
브레이크이븐 % = 블러프 사이즈 ÷ (팟 + 블러프 사이즈)

1/2팟 블러프: 50 ÷ 150 = 33% → 상대가 33% 이상 접으면 이득
2/3팟 블러프: 67 ÷ 167 = 40% → 상대가 40% 이상 접으면 이득
풀팟 블러프: 100 ÷ 200 = 50% → 상대가 50% 이상 접으면 이득
1.5x팟 블러프: 150 ÷ 250 = 60% → 상대가 60% 이상 접으면 이득
```

이 숫자를 체화하면 **"이 블러프가 돈이 되는가?"**를 즉석에서 판단할 수 있다.

### 임플라이드 오즈 (Implied Odds)

팟 오즈만으로는 콜이 안 되지만, **맞았을 때 추가로 딸 수 있는 금액**까지 고려하면 콜이 되는 경우.

```
현재 팟 오즈: 거터샷 4아웃 = 약 9%. 팟 오즈 20%. 수학적으로 콜 불가.

하지만:
  - 상대 스택이 깊다 (300BB 이상)
  - 내가 맞히면 넛 스트레이트
  - 상대가 오버페어를 가지고 있을 가능성 높음
  → 맞히면 상대 스택을 전부 가져올 수 있다
  → 임플라이드 오즈를 포함하면 콜이 +EV
```

임플라이드 오즈가 좋은 조건:
```
✅ 스택이 깊다 (100BB 이상)
✅ 맞히면 넛(최강)이다
✅ 상대가 강한 핸드를 가지고 있을 가능성 높다 (덤으로 돈을 더 딸 수 있다)
✅ 내 드로우가 히든(숨겨져 있다) — 상대가 눈치 못 챔

❌ 스택이 얕다 (40BB 이하)
❌ 맞혀도 2nd 넛이라 더 강한 핸드에 질 수 있다
❌ 보드가 뻔해서 상대가 드로우 완성을 눈치챈다
```

### 리버스 임플라이드 오즈 (Reverse Implied Odds)

반대 개념. **맞혔는데 상대가 더 강해서 추가로 돈을 잃는 경우.**

```
예: K♥J♥를 가지고 플러시 드로우.
보드: A♥ 9♥ 5♣

플러시를 맞히면 나는 킹 하이 플러시. 하지만 상대가 A♥ 가지고 있으면?
→ 상대는 넛 플러시. 나는 2nd 플러시.
→ 맞혔는데 오히려 큰 돈을 잃는다.

이런 상황에서는 팟 오즈가 맞아도 조심해야 한다.
```

## 2. MDF와 알파

### 블러프와 디펜스의 수학

이 두 개념은 GTO의 핵심이다. 어렵게 느껴질 수 있지만, 한번 이해하면 포커를 보는 눈이 완전히 달라진다.

### 알파 (α) — 블러프가 성공해야 하는 최소 폴드 빈도

위에서 본 브레이크이븐 포인트가 바로 알파다.

```
α = 베팅 사이즈 ÷ (팟 + 베팅 사이즈)

상대가 α 이상 접으면 → 어떤 핸드든 블러프가 이득
상대가 α 미만 접으면 → 블러프가 손해
```

| 베팅 사이즈 | α (최소 폴드율) |
|-----------|--------------|
| 1/4팟 | 20% |
| 1/3팟 | 25% |
| 1/2팟 | 33% |
| 2/3팟 | 40% |
| 3/4팟 | 43% |
| 풀팟 | 50% |
| 1.5x팟 | 60% |
| 2x팟 | 67% |

### MDF (Minimum Defense Frequency) — 최소 디펜스 빈도

MDF는 **상대 블러프를 허용하지 않기 위해, 내가 최소한 콜해야 하는 빈도**다.

```
MDF = 1 - α = 팟 ÷ (팟 + 베팅 사이즈)
```

| 상대 베팅 사이즈 | MDF (최소 콜 빈도) |
|-------------|--------------|
| 1/4팟 | 80% |
| 1/3팟 | 75% |
| 1/2팟 | 67% |
| 2/3팟 | 60% |
| 3/4팟 | 57% |
| 풀팟 | 50% |
| 1.5x팟 | 40% |
| 2x팟 | 33% |

### MDF의 실전 의미

> 상대가 2/3팟 베팅했다.
> MDF = 60%.
> 즉, 나는 레인지의 60% 이상을 콜(또는 레이즈)해야 상대의 블러프가 이득이 되지 않는다.
> 40% 이상 접으면 상대는 아무 카드로든 블러프해서 이득을 볼 수 있다.

**실전 적용**:

```
상대가 나를 너무 많이 블러프한다고 느낄 때:
→ "내가 MDF보다 많이 접고 있구나" → 콜 빈도를 올려야 한다

상대가 절대 블러프를 안 한다고 느낄 때:
→ MDF를 지킬 필요 없다 → 편하게 접어도 된다 (익스플로잇)
```

### 밸류 대 블러프 비율

GTO적으로 최적인 베팅 레인지는 밸류와 블러프의 비율이 정해져 있다.

```
2:1 룰 (풀팟 베팅 기준):
  밸류 2 : 블러프 1

→ 풀팟 베팅 시 상대 팟 오즈 = 33%
→ 상대가 33% 이상 이기면 콜
→ 내 레인지가 2/3 밸류 + 1/3 블러프이면, 상대는 정확히 33%로 이긴다
→ 상대는 콜해도 폴드해도 EV가 같다 = 완벽한 밸런스

베팅 사이즈별 최적 비율:
  1/3팟: 밸류 3 : 블러프 1 (75:25)
  1/2팟: 밸류 3 : 블러프 1 (75:25)
  2/3팟: 밸류 5 : 블러프 2 (71:29)
  풀팟:  밸류 2 : 블러프 1 (67:33)
  2x팟:  밸류 3 : 블러프 2 (60:40)
```

**핵심**: 사이즈가 클수록 블러프 비율을 높여도 된다. 상대에게 나쁜 팟 오즈를 주니까 접어야 하는 빈도가 높아지기 때문.

## 3. 레인지 어드밴티지와 넛 어드밴티지

### 왜 특정 보드에서 공격하고 특정 보드에서 체크하는가

C벳 전략의 근본 원리가 여기에 있다. 중급편에서는 "드라이 보드면 C벳, 웻 보드면 조심"이라고 배웠다. 이제 **왜**를 정확히 이해하자.

### 레인지 어드밴티지 (Range Advantage)

> **양쪽 레인지 전체를 비교했을 때, 한쪽의 평균 에퀴티가 더 높은 것.**

```
BTN 오픈, BB 콜. 플랍: A♠ K♦ 7♣

BTN 레인지: AA, AK, AQ, AJ, AT, KK, KQ, KJ, ... (에이스와 킹이 많다)
BB 레인지: A9, A8, KT, K9, 77, 98s, 87s, ... (약한 Ax, 수티드 커넥터)

→ BTN이 레인지 어드밴티지를 가진다.
  에이스와 킹이 보드에 있으므로 BTN 레인지의 평균 에퀴티가 높다.
→ BTN은 높은 빈도로 C벳 가능 (작은 사이즈, 넓은 레인지)
```

```
BTN 오픈, BB 콜. 플랍: 7♠ 6♦ 5♣

BTN 레인지: 오버카드 위주 (AK, AQ, KQ ...). 이 보드에 안 맞음.
BB 레인지: 76, 65, 87, 98, 54, 77, 66, 55, ... 이 보드에 잘 맞음.

→ BB가 레인지 어드밴티지를 가진다.
→ BTN은 C벳 빈도를 낮춰야 한다. 에어로 베팅해도 BB가 콜.
```

### 넛 어드밴티지 (Nut Advantage)

> **양쪽 레인지 중 최강 핸드(넛)를 누가 더 많이 가지고 있는가.**

```
BTN 오픈, BB 콜. 플랍: A♠ A♦ 7♣

넛 어드밴티지: BTN
  BTN 레인지에 AA(쿼드), AK, AQ, AJ이 있다.
  BB 레인지에는 AA가 거의 없다 (3벳했을 것).

→ BTN이 넛 어드밴티지. 큰 사이즈 베팅 가능.
  상대가 최강 핸드가 없으니까, 큰 압박을 넣을 수 있다.
```

```
BTN 오픈, BB 콜. 플랍: 8♠ 7♠ 6♠

넛 어드밴티지: BB
  BB 레인지에 86s, 87s, 76s, 98s, 55, T9s, A♠x 등이 있다.
  BTN 레인지에도 일부 있지만, BB가 플러시/스트레이트 조합이 더 많다.

→ BB가 넛 어드밴티지. BTN은 큰 C벳을 하면 안 됨.
  넛이 상대에게 많으면, 큰 베팅은 자살 행위.
```

### 두 어드밴티지의 조합

```
레인지 어드밴티지 + 넛 어드밴티지 = 높은 빈도, 다양한 사이즈 가능
  → 가장 공격적으로 플레이할 수 있는 보드
  예: AK7 레인보우 (BTN vs BB)

레인지 어드밴티지만 = 높은 빈도, 작은 사이즈
  → 많은 핸드로 작게 베팅
  예: Q83 레인보우 (BTN vs BB)

넛 어드밴티지만 = 낮은 빈도, 큰 사이즈
  → 선별된 핸드로 크게 베팅 (폴라라이즈)
  예: 876 투톤 (BB vs BTN, BB가 체크레이즈 빈도 높음)

어드밴티지 없음 = 체크 위주
  → 765 레인보우 같은 보드에서 BTN은 많이 체크
```

### 실전 빠른 판단법

플랍이 깔리면 2가지를 3초 안에 판단:

```
1. "이 보드에서 내 레인지가 유리한가?"
   → 높은 카드 보드 (A, K 포함) = 오프너(레이저)에게 유리
   → 낮은 카드/연결된 보드 = 콜러에게 유리

2. "이 보드에서 넛을 누가 더 많이 가지고 있는가?"
   → 에이스 페어드 보드 = 오프너가 넛 (AA, AK)
   → 로우 보드 = 콜러가 넛 (셋, 투페어, 스트레이트)
```

## 4. 캡드 레인지

### 상대의 천장 읽기

**캡드 레인지(Capped Range)**란 레인지에서 최강 핸드가 빠져 있는 상태를 말한다.

### 캡드가 되는 순간

```
상황 1: 프리플랍에서 3벳 안 한 콜러
  CO 오픈, BTN 콜.
  → BTN의 레인지에서 AA, KK, AKs는 빠졌다 (3벳했을 테니까).
  → BTN의 레인지는 "캡드" — 천장이 QQ, AQs 정도.

상황 2: 플랍에서 C벳에 콜만 한 사람
  BTN C벳, BB 콜.
  → BB 레인지에서 셋, 투페어 일부는 빠졌을 수 있다 (체크레이즈했을 테니까).
  → BB 레인지가 "부분적으로 캡드".

상황 3: 턴에서 체크-체크 후
  플랍 C벳 → 콜 → 턴 체크-체크.
  → 양쪽 모두 강한 핸드를 가질 가능성이 줄었다.
  → 특히 IP(오프너)가 턴 체크 = 오버페어, TPTK가 없을 가능성.
  → IP 레인지가 캡드.
```

### 캡드 레인지를 공략하는 법

상대 레인지가 캡드되었다는 건, **상대에게 넛이 없다**는 뜻이다. 이건 기회다.

```
공략 1: 오버벳
  상대 레인지에 넛이 없으면, 큰 사이즈 베팅이 효과적.
  상대는 최강 핸드가 없으므로, 큰 베팅에 콜하기 매우 어렵다.

  예: 플랍 C벳 → 콜 → 턴 체크-체크 → 리버
  IP가 턴에서 체크했으므로 IP 레인지 캡드.
  OOP는 리버에서 오버벳 가능! (밸류든 블러프든)

공략 2: 프로빙 벳
  IP가 턴에서 체크하면 IP 레인지 캡드.
  OOP는 턴 또는 리버에서 "프로빙 벳"(선제 베팅)을 할 수 있다.
  상대가 약한 레인지를 가지고 있으니까 작은 베팅에도 많이 접는다.
```

### 자기 레인지가 캡드되지 않게 하려면

```
핵심: 체크 레인지에 강한 핸드를 섞어라.

나쁜 습관: 강한 핸드는 항상 베팅, 약한 핸드만 체크
→ 체크하면 상대가 "아, 약하구나" → 공격 시작
→ 내 체크 레인지가 캡드

좋은 습관: 가끔 강한 핸드도 체크
→ 상대가 "체크했지만 뭔가 있을 수도" → 함부로 공격 못 함
→ 내 체크 레인지가 보호됨 (=언캡드)
```

## 5. SPR

### 팟과 스택의 관계가 전략을 결정한다

**SPR(Stack to Pot Ratio)** = 잔여 스택 ÷ 팟 크기

```
예: 플랍 시점에서 팟 30BB, 내 스택 100BB
SPR = 100 ÷ 30 ≈ 3.3
```

### SPR에 따른 전략 변화

#### 높은 SPR (10+) — 딥 스택 포커

```
특징:
  - 스택이 팟에 비해 매우 크다
  - 여러 스트릿에 걸쳐 팟을 키울 수 있다
  - 드로우의 임플라이드 오즈가 매우 좋다
  - 미묘한 포스트플랍 스킬이 중요

전략:
  - 수티드 커넥터, 스몰 페어의 가치 상승 (맞히면 스택을 가져감)
  - TPTK도 3스트릿 밸류가 확실하지 않을 수 있음
  - 블러프가 비싸지만, 성공 시 보상도 크다
  - 포지션 가치 극대화
```

#### 중간 SPR (3-10) — 표준 포커

```
특징:
  - 가장 일반적인 상황 (100BB 시작, 표준 프리플랍 레이징)
  - 2-3스트릿 베팅으로 올인 도달 가능
  - 밸런스 잡힌 전략 필요

전략:
  - 오버페어, TPTK로 3스트릿 밸류 베팅 편하게 가능
  - 드로우의 팟 오즈/임플라이드 오즈 계산 필요
  - 표준적인 C벳, 더블배럴, 트리플배럴 전략
```

#### 낮은 SPR (1-3) — 올인 포커

```
특징:
  - 3벳 팟, 4벳 팟에서 흔함
  - 한두 번 베팅이면 올인
  - 복잡한 멀티스트릿 플래닝이 불필요
  - "맞았으면 가고, 안 맞았으면 포기"

전략:
  - 탑 페어이면 보통 올인까지 가도 OK
  - 오버페어는 무조건 올인
  - 드로우의 임플라이드 오즈가 낮다 (추가로 딸 돈이 별로 없음)
  - 셋이 아니면 스몰 페어의 가치 급감
  - "간단한 포커" — 뇌를 쉽게 쓸 수 있지만, 편차가 크다
```

#### 매우 낮은 SPR (<1) — 거의 올인

```
특징:
  - 4벳 팟이나 숏스택 상황
  - 에퀴티 실현만 생각하면 됨
  - 블러프는 의미 없음 (스택이 너무 작아서)

전략:
  - 에이스 높으면 올인
  - 페어 맞으면 올인
  - 수학적 계산(에퀴티)만으로 결정
```

### SPR 실전 적용

```
프리플랍에서 SPR을 미리 계산하라:

싱글 레이즈 팟 (3BB 오픈 + 콜):
  팟 ≈ 7.5BB, 스택 ≈ 97BB → SPR ≈ 13 (높음)

3벳 팟 (3BB 오픈 + 10BB 3벳 + 콜):
  팟 ≈ 21.5BB, 스택 ≈ 90BB → SPR ≈ 4 (중간-낮음)

4벳 팟 (3BB + 10BB + 25BB + 콜):
  팟 ≈ 52BB, 스택 ≈ 75BB → SPR ≈ 1.4 (매우 낮음)
```

이 SPR을 알면 플랍이 깔리기 전에 이미 전략이 정해진다.

## 6. 3벳 팟과 4벳 팟

### 프리플랍이 커지면 포스트플랍이 달라진다

3벳 팟과 4벳 팟은 싱글 레이즈 팟과 완전히 다른 게임이다.

### 3벳 팟 포스트플랍

SPR ≈ 3-5. 2스트릿이면 올인.

```
핵심 변화:
1. C벳 빈도 감소
   싱글 레이즈 팟: C벳 60-80%
   3벳 팟: C벳 40-60%
   → 팟이 크므로 베팅 비용이 높다. 더 선별적으로.

2. C벳 사이즈 감소
   싱글 레이즈 팟: 1/3 ~ 2/3팟
   3벳 팟: 1/4 ~ 1/3팟
   → 이미 팟이 크므로 작은 %도 절대값은 큼.

3. 오버페어의 가치 상승
   SPR이 낮으므로 오버페어로 올인까지 편하게 갈 수 있다.
   싱글 레이즈 팟에서 QQ는 고민이었지만, 3벳 팟에서 QQ는 강하다.

4. 드로우의 가치 하락
   SPR이 낮아 임플라이드 오즈가 줄었다.
   플러시 드로우로 콜하기 어려울 수 있다.
```

#### 3벳 팟에서의 보드별 전략

```
A하이 보드 (A-8-3):
  3벳터에게 극도로 유리 (레인지 + 넛 어드밴티지 모두)
  → 높은 빈도, 작은 사이즈 C벳

K하이 보드 (K-7-2):
  3벳터에게 유리하지만 A하이만큼은 아님
  → 높은 빈도 C벳, 다만 상대 AK 불리가 사라짐

로우 보드 (7-5-3):
  3벳터의 오버카드 레인지에 안 맞음
  → 체크 빈도 증가. 선별적 C벳.

연결 보드 (J-T-9):
  양쪽 레인지에 히트 가능
  → 매우 주의. 강한 핸드 위주로만 베팅.
```

### 4벳 팟 포스트플랍

SPR ≈ 1-2. 한 번 베팅이면 올인.

```
간단한 룰:
1. 페어 맞으면 올인
2. 오버카드 두 장(AK)이면 C벳 → 콜 받으면 대부분 올인
3. 에어면 작은 C벳 후 포기하거나, 보드에 따라 체크/폴드
4. 수학적 계산 위주. "이 핸드의 에퀴티가 올인 가격에 맞는가?"
```

## 7. 동크 벳

### 규칙을 깨는 선빵

**동크 벳(Donk Bet)** = 프리플랍에서 콜한 사람이 플랍에서 먼저 베팅하는 것.

"동크"라는 이름이 좀 무시하는 느낌이지만, 올바르게 사용하면 강력한 무기다.

### 왜 동크 벳은 보통 "나쁜" 플레이인가

```
일반적인 흐름:
  1. 프리플랍 레이저가 이니셔티브를 가지고 있다
  2. 플랍에서 콜러가 먼저 행동
  3. 콜러는 체크 → 레이저가 C벳할지 결정

동크 벳이 보통 나쁜 이유:
  - 레이저의 C벳 기회를 뺏는다 (레이저가 에어로 C벳할 기회를 없앰)
  - 약한 핸드로 동크하면 레이즈 당할 수 있다
  - 강한 핸드로 동크하면 체크레이즈 기회를 놓친다
```

### 그런데 언제 동크 벳이 좋은가?

```
좋은 동크 벳 스팟:

1. 보드가 콜러에게 극도로 유리할 때
   예: BB에서 BTN 오픈에 콜. 플랍: 7♠ 6♠ 5♥
   → 이 보드는 BB 레인지에 유리 (수티드 커넥터, 스몰 페어)
   → BTN은 어차피 이 보드에서 많이 체크할 것
   → BB가 먼저 공격하면 BTN은 대응하기 어려움

2. 멀티웨이 팟에서 강한 핸드일 때
   예: BB에서 콜. CO, BTN도 콜. 플랍: 8♠ 8♦ 3♣
   → 내가 83s로 풀하우스. 멀티웨이라 누군가는 C벳 안 할 수도.
   → 동크 베팅으로 직접 밸류를 뽑는다.

3. 턴/리버에서 드로우가 완성되었을 때
   예: 플랍 체크-C벳-콜. 턴: 플러시 완성 카드.
   → 내가 플러시를 가지고 있으면 동크 벳으로 밸류 추출.
   → 상대가 체크할 가능성이 높은 턴 카드이므로, 내가 먼저 베팅.
```

### 홈게임에서의 동크 벳

```
홈게임에서 약한 플레이어의 동크 벳은 보통 강한 핸드다.
"동크 = 맞았다!"인 경우가 많다.
→ 약한 상대가 동크 베팅하면 존중하고, 약한 핸드는 접어라.

반면, 이 공략집을 읽은 당신은:
→ 전략적 동크 벳으로 상대를 혼란시킬 수 있다.
→ 하지만 남용하지 말 것. 좋은 스팟에서만 사용.
```

## 8. 프로빙 벳과 딜레이드 C벳

### 상대의 약점을 찌르는 두 가지 도구

### 프로빙 벳 (Probing Bet)

```
정의: IP(레이저)가 플랍에서 체크한 후, OOP(콜러)가 턴에서 베팅하는 것.

왜 효과적인가:
  1. IP가 플랍에서 체크 = IP 레인지가 캡드
  2. IP에게 강한 핸드가 없을 가능성이 높다
  3. OOP가 턴에서 공격하면 IP는 약한 레인지로 디펜스해야 한다

프로빙 벳 사이즈: 1/4 ~ 1/3팟 (작게)
  → IP 레인지가 약하므로 작은 베팅에도 많이 접는다
  → 작은 투자로 팟을 가져올 수 있다

좋은 프로빙 핸드:
  ✅ 약한 탑 페어 (체크레이즈 안 한 중간 핸드)
  ✅ 미들 페어 (작은 밸류 + 보호)
  ✅ 에어 + 블로커 (블러프)
  ✅ 드로우 (세미블러프)
```

### 딜레이드 C벳 (Delayed C-bet)

```
정의: IP(레이저)가 플랍에서 체크하고, 턴에서 베팅하는 것.

프로빙 벳과의 차이:
  프로빙: OOP가 IP의 체크를 찌르는 것
  딜레이드 C벳: IP가 의도적으로 플랍을 체크하고, 턴에서 공격

왜 효과적인가:
  1. 플랍에서 체크 → 상대가 "약하구나" 생각 → 가드를 내림
  2. 턴에서 베팅 → 기습 공격
  3. 플랍에서 C벳 빈도가 너무 높으면 예측 가능 → 딜레이드로 변화를 줌

좋은 딜레이드 C벳 스팟:
  ✅ 플랍에서 에어 + 백도어 드로우 → 턴에서 드로우 완성 → 세미블러프
  ✅ 플랍에서 약한 페어 → 플랍 체크(팟 컨트롤) → 턴 카드 유리 → 베팅
  ✅ 상대가 플랍 체크레이즈를 많이 하는 보드 → 플랍 회피 → 턴 공격
```

### 두 도구의 핵심 공통점

```
둘 다 "플랍 체크" 이후에 일어나는 액션이다.

"플랍에서 체크가 일어났다 = 양쪽 레인지에 변화가 생겼다"

이 변화를 이용하는 것이 프로빙/딜레이드의 본질.
체크는 정보를 준다. 그 정보를 활용하라.
```

## 9. 체크 레인지 구축

### 강한 핸드를 숨기는 기술

중급편에서 "가끔 강한 핸드도 체크하라"고 했다. 이제 **어떤 강한 핸드를 얼마나 체크하는지**를 구체적으로 다룬다.

### 왜 체크 레인지가 필요한가

```
만약 내가 항상 강하면 베팅, 약하면 체크한다면:

상대의 대응:
  → 내가 베팅하면 "강하구나" → 자기도 강할 때만 콜
  → 내가 체크하면 "약하구나" → 공격적으로 블러프

결과: 베팅에서 밸류를 못 뽑고, 체크하면 블러프에 시달린다.

해결: 체크할 때 강한 핸드를 섞어서 상대가 함부로 공격 못 하게.
```

### IP에서의 체크 레인지

```
IP(마지막 행동)에서는 체크해도 상대가 공격할 기회가 적다.
→ IP의 체크 레인지는 상대적으로 약해도 괜찮다.
→ 하지만 일부 강한 핸드는 체크해야 한다 (팟 컨트롤, 트랩).

IP 체크 후보:
  - 중간 오버페어 (JJ on Q-high 보드) → 팟 컨트롤
  - 미들 셋 (55 on A-5-3 보드) → 슬로우플레이, 상대 블러프 유도
  - 약한 탑 페어 → 2스트릿으로 충분. 3스트릿은 과잉.
```

### OOP에서의 체크 레인지

```
OOP(먼저 행동)에서는 체크 레인지가 더 중요하다.
→ 체크하면 상대가 베팅할 기회를 갖는다.
→ 체크 레인지가 약하면 상대가 무자비하게 C벳.

OOP 체크 레인지에 반드시 포함할 핸드:
  - 체크레이즈용 셋/투페어
  - 강한 드로우 (체크레이즈 세미블러프)
  - 일부 오버페어 (트랩)

이렇게 하면 상대가 "체크했지만 강할 수도" → C벳 빈도 감소 → 내 약한 핸드도 보호.
```

### 밸런스의 예시

```
보드: K♠ 8♦ 3♣. 나는 BB, BTN이 C벳.

만약 내가 이 보드에서:
  셋(88, 33): 항상 체크레이즈
  투페어(K8, K3): 항상 체크레이즈
  탑페어(KQ, KJ): 항상 콜
  약한 핸드: 항상 폴드

→ 상대가 이걸 눈치채면:
  "콜만 하면 탑페어겠지" → 턴에서 큰 배럴로 접게 만들기
  "체크레이즈 = 넛" → 접으면 됨

밸런스 잡힌 전략:
  셋(88, 33): 70% 체크레이즈 / 30% 콜
  투페어(K8): 50% 체크레이즈 / 50% 콜
  탑페어(KQ): 50% 콜 / 50% 체크레이즈(블러프와 섞어서)
  강한 드로우: 체크레이즈 (블러프로)
  약한 핸드: 폴드 or 가끔 블러프 체크레이즈

→ 상대가 내 액션만 보고 핸드를 추론하기 어려워진다.
```

## 10. 리버 레이즈

### 최후의 무기

리버에서 상대 베팅에 콜하지 않고 **레이즈**하는 것은 가장 강한 액션이다. 가장 많은 돈이 걸리고, 가장 큰 결정을 강요한다.

### 리버 레이즈의 2가지 목적

#### 밸류 리버 레이즈
```
"상대가 콜할 수 있는 더 강한 핸드를 가지고 있다"

예:
  보드: K♠ 8♦ 3♣ 5♥ 2♠
  내 핸드: 88 (미들 셋)
  상대 리버 베팅: 2/3팟

  상대 레인지: AK, KQ, KJ로 탑 페어 밸류벳 가능성.
  → 내가 레이즈하면 AK는 콜할 수 있다 (탑 페어 탑 키커).
  → 밸류 레이즈!

조건:
  ✅ 상대가 강한 핸드(탑 페어+)로 베팅하고 있을 때
  ✅ 내가 상대보다 확실히 강할 때
  ✅ 상대가 레이즈에 콜할 수 있는 핸드가 충분할 때
```

#### 블러프 리버 레이즈
```
"상대가 중간 핸드(블러프캐처)를 접게 만든다"

예:
  보드: K♠ 9♥ 7♥ 3♦ 2♣
  내 핸드: A♥5♥ (플러시 드로우 미스 = 에어)
  상대 리버 베팅: 1/2팟

  나는 에어. 콜해봤자 진다. 하지만:
  → 상대가 KJ, KT 같은 중간 탑 페어로 씬밸류벳 했다면
  → 내가 레이즈하면 상대는 "셋? 투페어?" 생각하고 접을 수 있다
  → A♥ 블로커로 상대의 넛 플러시 가능성도 차단

이건 매우 고급 기술. 조건이 맞을 때만.

조건:
  ✅ 상대의 베팅 레인지에 블러프캐처(중간 핸드)가 많을 때
  ✅ 내가 블로커를 가지고 있을 때 (넛 핸드 가능성 차단)
  ✅ 내 라인이 "강한 핸드"와 일치할 때 (스토리가 말이 됨)
  ✅ 상대가 폴드할 수 있는 플레이어일 때 (콜링 스테이션 NO)
```

### 리버 레이즈 사이즈

```
밸류 레이즈: 2.5x ~ 3x (상대 베팅의 2.5~3배)
  → 상대가 콜할 수 있는 최대 금액
  → 너무 크면 블러프 같아서 접힘, 너무 작으면 밸류를 못 뽑음

블러프 레이즈: 2.2x ~ 2.5x
  → 상대를 접게 만드는 최소한의 사이즈
  → 불필요하게 크게 하지 않는다 (리스크 최소화)
  → 올인이 옵션이면 올인이 가장 큰 압박
```

## 11. 빈도와 밸런스

### GTO의 실전 적용

GTO를 완벽하게 실행하는 건 불가능하다. 하지만 **GTO의 원리를 이해하고 대략적으로 적용하는 것**은 가능하고, 매우 효과적이다.

### 빈도 기반 사고

```
"이 스팟에서 내 레인지의 몇 %를 베팅하고, 몇 %를 체크해야 하는가?"

이렇게 생각하는 것이 빈도 기반 사고다.
핸드 하나하나를 개별적으로 판단하는 게 아니라,
"이 카테고리의 핸드는 대략 X% 베팅, Y% 체크"라고 정하는 것.
```

### 주요 스팟의 대략적인 빈도

```
IP C벳 (싱글 레이즈 팟):
  A하이 드라이 보드: 80-90% 베팅 (작은 사이즈)
  K하이 드라이 보드: 65-75% 베팅
  미디엄 보드: 50-60% 베팅
  로우 커넥트 보드: 30-40% 베팅 (체크 많이)

턴 배럴 (C벳 후):
  플랍 C벳에 콜 받았을 때: 50-60% 턴 베팅
  스케어 카드 떨어짐: 빈도 증가
  로우 브릭: 빈도 유사하거나 약간 감소
  드로우 완성 카드: 상황에 따라 크게 변동

리버 베팅:
  밸류: 핸드 강도에 따라
  블러프: 밸류 대 블러프 비율 맞추기 (사이즈에 따라)
```

### 밸런스가 중요한 스팟 vs 안 중요한 스팟

```
밸런스가 중요한 스팟 (상대가 강한 플레이어):
  - 3벳 팟에서의 C벳 결정
  - 리버 밸류벳 vs 블러프 비율
  - 체크레이즈 빈도
  → 강한 상대는 내 패턴을 읽으므로, 밸런스가 필요

밸런스가 덜 중요한 스팟 (상대가 약한 플레이어):
  - 홈게임에서 콜링 스테이션 상대
  - 자신의 핸드에만 집중하는 초보 상대
  → 익스플로잇이 더 효과적. 밸런스보다 약점 공략.
```

### 실전에서의 밸런스 팁

```
완벽한 밸런스는 불가능하다. 대신 이것만 지키자:

1. "항상 베팅"하는 핸드 카테고리와 "항상 체크"하는 카테고리를 없애라
   → 모든 카테고리에 약간의 혼합을 넣어라

2. 블러프를 칠 때, 밸류 핸드도 같은 라인으로 올 수 있는지 확인하라
   → "이 라인에서 내가 강한 핸드를 가질 수도 있나?" YES면 블러프 OK.

3. 강한 핸드를 가끔 체크하라
   → 10번 중 2-3번만 체크해도 상대는 확신을 못 갖게 된다

4. 시간 단위로 생각하라
   → 한 핸드에서 밸런스를 맞추는 게 아니라, 전체 세션에서 밸런스
```

## 12. 스택 사이즈별 전략 조정

### 100BB가 아닐 때

대부분의 전략은 100BB(빅 블라인드 100배) 기준이다. 하지만 실전에서는 다양한 스택 사이즈를 만난다.

### 딥 스택 (150BB+)

```
변화:
  - 수티드 커넥터, 스몰 페어의 가치 대폭 상승
  - 임플라이드 오즈 극대화 (맞히면 큰 스택을 가져옴)
  - 탑 페어의 상대적 가치 하락 (3스트릿 밸류가 위험해짐)
  - 포지션의 가치 극대화

조정:
  ✅ 투기적 핸드(수티드 커넥터, 스몰 페어) 더 넓게 플레이
  ✅ 탑 페어로 팟 컨트롤 (체크 빈도 증가)
  ✅ 셋, 스트레이트, 플러시 맞히면 적극적으로 팟 키우기
  ❌ 탑 페어 탑 키커로 스택 전부 투자하기 (오버플레이 위험)
```

### 숏 스택 (40-60BB)

```
변화:
  - 프리플랍이 더 중요해진다 (포스트플랍 여유가 적음)
  - 3벳 팟이면 거의 올인 상황
  - 임플라이드 오즈 감소 (투기적 핸드 가치 하락)
  - 올인 에퀴티가 중요

조정:
  ✅ 프리미엄 핸드로 공격적으로 (3벳 후 올인 각)
  ✅ 수티드 커넥터, 스몰 페어 줄이기 (임플라이드 부족)
  ❌ 복잡한 멀티스트릿 플래닝 (스택이 부족해서 의미 없음)
  ✅ "맞았으면 가고, 안 맞았으면 접는다" 마인드
```

### 커버링 vs 커버드 (Covering vs Covered)

```
상대보다 스택이 클 때 (커버링):
  → 상대의 스택 사이즈를 기준으로 SPR을 계산
  → 상대의 전체 스택을 리스크에 놓을 수 있다
  → 더 공격적으로 플레이 가능

상대보다 스택이 작을 때 (커버드):
  → 내 스택이 기준. 올인 결정이 더 중요.
  → 조심스럽게. 내 스택 전체가 리스크.
```

### 홈게임 스택 팁

```
홈게임에서는 리바이(재구매)가 자유로운 경우가 많다.

원칙:
  1. 테이블에서 가장 큰 스택을 유지하려고 노력하라
     → 딥 스택일수록 스킬 에지가 커진다
  2. 숏 스택이 되면 리바이하라 (여유가 되면)
     → 40BB 이하는 전략 자체가 달라져서 불리
  3. 상대 스택 사이즈를 항상 파악하라
     → "이 사람은 30BB밖에 없구나" → 올인 각도 고려
```

## 13. 메타게임

### 테이블 밖의 싸움

메타게임이란 **현재 핸드를 넘어서, 이전 핸드들의 역사와 미래 핸드에 대한 기대가 전략에 미치는 영향**이다.

### 이미지 관리

```
타이트 이미지:
  나: 1시간 동안 거의 폴드만 했다.
  상대 인식: "저 사람은 좋은 패만 해."

  활용: 블러프의 가치 상승!
  → 내가 베팅하면 상대가 "진짜겠지" 하고 접는다.
  → 타이트 이미지 구축 후 블러프 = 매우 효과적.

루즈 이미지:
  나: 많은 핸드에 참여하고, 블러프도 들켰다.
  상대 인식: "저 사람은 뭘로든 해."

  활용: 밸류벳의 가치 상승!
  → 내가 베팅하면 상대가 "또 블러프겠지" 하고 콜.
  → 루즈 이미지 구축 후 강한 핸드 = 큰 밸류.
```

### 쇼다운 활용

```
블러프가 들킨 후:
  → 상대가 나를 블러퍼로 인식
  → 다음 1-2시간 동안 밸류벳이 더 많이 콜 받음
  → 이걸 의식적으로 활용하라

넛을 보여준 후:
  → 상대가 나를 타이트한 플레이어로 인식
  → 다음 블러프 기회에 성공률 상승
  → "저번에 AA 보여줬잖아" → "이번에도 뭔가 있겠지" → 폴드
```

### 상대별 히스토리

```
특정 상대와의 과거 경험이 현재 전략에 영향:

"저번에 이 사람한테 큰 블러프 성공했다"
  → 이 사람은 나를 경계할 것
  → 다음에는 밸류벳 위주로
  → 한동안 블러프를 줄여야 상대가 가드를 내림

"이 사람은 나한테 항상 접는다"
  → 블러프 빈도를 높여라
  → 하지만 어느 순간 상대도 적응할 수 있으니 과하지 않게

"이 사람한테 큰 배드빗을 줬다"
  → 상대가 틸트 상태일 수 있음
  → 밸류벳 위주로 + 블러프 줄이기 (틸트된 사람은 안 접음)
```

### 의도적 정보 공개

```
고급 기술: 의도적으로 핸드를 보여주기

블러프 성공 후 일부러 보여주기:
  → "보셨죠? 저 블러프도 합니다"
  → 이후 밸류벳에 대한 콜 빈도 상승
  → 단기적 자존심 손상이지만 장기적으로 이득

넛 핸드로 접히게 만든 후 보여주기:
  → "이런 핸드도 있었어요"
  → 상대가 다음에 내 베팅을 더 존중
  → 블러프 성공률 상승
```

## 14. 게임 셀렉션

### 가장 +EV인 결정

아이러니하지만, 포커에서 가장 수익에 영향을 미치는 결정은 **카드를 받기도 전에 내려진다.** 어떤 게임에 앉을 것인가.

### 좋은 게임의 조건

```
1순위: 약한 플레이어가 있는가?
  → 1-2명의 약한 플레이어(피쉬)가 있으면 전체 테이블이 +EV
  → "테이블에서 피쉬가 누군지 모르겠으면, 그 피쉬는 나다"

2순위: 내 왼쪽에 누가 앉아 있는가?
  → 내 왼쪽(= 내 뒤에서 행동) = 내 플레이에 가장 큰 영향
  → 왼쪽에 어그레시브한 강한 플레이어가 있으면 불리
  → 왼쪽에 패시브/약한 플레이어가 있으면 유리

3순위: 스택 사이즈
  → 딥 스택 게임일수록 스킬 에지가 크다
  → 모두 100BB+ 가지고 있는 게임이 좋다

4순위: 테이블 분위기
  → 재미있고 사교적인 테이블 = 플레이어들이 루즈하게 플레이
  → 긴장되고 조용한 테이블 = 모두 집중, 에지 적음
```

### 자리 선택 (Seat Selection)

```
이상적인 자리 배치:

내 오른쪽 (나보다 먼저 행동):
  → 루즈한 플레이어, 약한 플레이어
  → 이유: 그들의 약한 플레이를 관찰한 후 내가 대응 가능

내 왼쪽 (나보다 나중에 행동):
  → 타이트한 플레이어, 패시브한 플레이어
  → 이유: 내가 오픈해도 3벳을 잘 안 함 → 내 오픈 빈도 높일 수 있음
```

### 떠나야 할 때

```
❌ 테이블에 약한 플레이어가 없고, 모두 잘 치고 있을 때
❌ 내가 틸트 상태일 때
❌ 집중력이 떨어졌을 때 (피곤, 음주 등)
❌ 내 왼쪽에 매우 강한 어그레시브 플레이어가 있을 때
❌ 세션 시작 후 계속 지고 있어서 감정적으로 불안정할 때

"떠나는 것도 +EV 플레이다."
```

## 15. 고급 실전 체크리스트

### 매 핸드 사고 프레임워크 (고급)

```
프리플랍:
  □ 내 포지션과 스택 사이즈(SPR) 확인
  □ 상대들의 스택 사이즈와 유형 파악
  □ RFI/3벳/4벳 결정
  □ 멀티스트릿 플랜의 대략적인 그림 (이 핸드로 몇 스트릿?)

플랍:
  □ 레인지 어드밴티지는 누구에게 있는가?
  □ 넛 어드밴티지는 누구에게 있는가?
  □ → 어드밴티지에 맞는 빈도와 사이즈 선택
  □ 상대 레인지 추정 (프리플랍 액션 기반)
  □ 체크 레인지에 강한 핸드를 포함했는가?

턴:
  □ 턴 카드가 누구에게 유리한가?
  □ 상대 레인지를 플랍 액션으로 업데이트
  □ 상대 레인지가 캡드되었는가?
  □ 내 레인지가 캡드되었는가?
  □ 계속 배럴할 것인가, 속도를 줄일 것인가?

리버:
  □ 밸류벳: 콜 받았을 때 이기는 빈도가 50% 이상인가?
  □ 블러프: 상대 레인지에 블러프캐처가 충분하고, 폴드할 것인가?
  □ 블러프캐칭: 상대 레인지에 블러프가 충분한가? (MDF 참고)
  □ 블로커를 활용하고 있는가?
```

### 고급자가 빠지기 쉬운 함정 TOP 5

| 순위 | 함정 | 해결 |
|------|------|------|
| 1 | **레벨링 전쟁** — "상대가 내가 블러프라고 생각하니까 밸류벳을 해야 하는데, 상대도 그걸 아니까..." | 1-2 레벨만 생각하라. 홈게임에서 3레벨 이상은 대부분 오버씽킹. |
| 2 | **GTO 맹신** — GTO 빈도에 집착해서 익스플로잇 기회를 놓침 | 약한 상대에게는 익스플로잇이 정답. GTO는 프레임워크일 뿐. |
| 3 | **화려한 플레이 중독** — 블러프 레이즈, 오버벳에 매력을 느끼고 남용 | 화려함 = 분산 증가. 기본에 충실한 게 수익의 80%. |
| 4 | **결과 지향 사고** — 한 번의 큰 팟 결과에 멘탈이 흔들림 | EV로 생각하라. 올바른 결정 + 나쁜 결과 = OK. |
| 5 | **공부 > 실전** — 이론을 너무 많이 공부하고 실전에서 적용을 안 함 | 한 가지 개념을 배우면 즉시 실전에서 시도하라. |

> **고급편 마무리:**
>
> 초보편은 "뭘 플레이할까"를 알려줬고,
> 중급편은 "왜 이렇게 플레이하는가"를 알려줬고,
> 이 고급편은 "상대가 나를 어떻게 공략하고, 나는 그걸 어떻게 이용하는가"를 알려줬다.
>
> 여기까지 읽고 소화했다면, 당신은 대부분의 홈게임과 로우 스테이크 펍에서
> 테이블의 최강자가 될 충분한 지식을 갖추고 있다.
>
> 하지만 지식과 실력은 다르다. 이론을 실전으로 바꾸는 건 오직 **반복**뿐이다.
> 트레이너에서 매일 연습하고, 세션마다 복기하고, 이 공략집을 반복해서 읽어라.
>
> 결국 남는 건 습관이다.
