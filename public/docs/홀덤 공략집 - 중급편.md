## 1. 레인지 씽킹

### 핸드가 아니라 범위로 생각하라

초보는 이렇게 생각한다: *"상대가 AA인가? KK인가?"*
중급자는 이렇게 생각한다: *"상대의 레인지에는 어떤 핸드들이 있을까?"*

이 차이가 엄청나다. 상대의 정확한 핸드를 맞히는 건 불가능하다. 하지만 **상대가 가지고 있을 수 있는 핸드들의 범위(레인지)를 좁혀가는 것**은 가능하고, 이게 포커의 핵심 스킬이다.

### 레인지를 좁히는 3단계

#### 1단계: 프리플랍 액션으로 초기 레인지 설정

상대가 어떤 포지션에서 어떤 액션을 했는가?

```
UTG 오픈 → 상위 10%의 핸드 (AA-77, AKs-ATs, 브로드웨이 수티드, AKo-AJo, KQo)
CO 오픈 → 상위 30%의 핸드 (위 + 44-33, 다양한 수티드, 브로드웨이 오프수트)
BTN 오픈 → 상위 51%의 핸드 (거의 절반)

UTG 오픈에 3벳한 사람 → 매우 좁은 레인지 (AA, KK, QQ, AKs + 블러프 약간)
BTN 오픈에 3벳한 사람 → 상대적으로 넓은 레인지
```

**예시**:
> CO가 오픈, BTN이 3벳, CO가 콜.
> BTN의 레인지: AA-JJ, AKs-AJs, KQs, A5s-A4s, AKo (밸류+블러프)
> CO의 레인지: QQ-77, AQs-ATs, KQs-KJs, QJs, AQo (3벳 콜 레인지)

이 시점에서 이미 상대가 가질 수 있는 핸드가 크게 좁혀진다.

#### 2단계: 플랍 액션으로 레인지 좁히기

플랍: K♠ 8♦ 3♣ (드라이 보드)

```
상대가 C벳 → 넓은 레인지 (드라이 보드에서 C벳은 빈도 높음. 맞든 안 맞든 베팅)
상대가 체크 → 레인지에서 강한 핸드 일부 제거 (AK, KK, AA는 보통 C벳)
                단, 트랩 가능성도 있으므로 100% 약한 건 아님
```

#### 3단계: 턴/리버 액션으로 최종 좁히기

턴: K♠ 8♦ 3♣ 5♠

```
상대가 플랍에서 C벳 → 턴에서 또 베팅(더블배럴)
→ 레인지가 더 좁아짐: 진짜 강한 핸드(KK, AK, 88) + 드로우 + 블러프
→ 중간 강도(KJ, KT)는 턴에서 체크하는 경우가 많음

상대가 플랍 C벳 → 턴 체크
→ "쇼다운 밸류는 있지만 3스트릿 밸류는 없는 핸드" 가능성
→ 또는 포기한 블러프
```

### 레인지 씽킹 연습법

매 핸드 끝나면(쇼다운이든 폴드든) 이 질문을 하자:

> "상대의 프리플랍 액션 → 플랍 액션 → 턴 액션을 보면, 어떤 핸드가 말이 되는가?"

처음에는 느리다. 하지만 100번 하면 자동화된다. 이게 "상대를 읽는다"는 것의 실체다.

## 2. 멀티스트릿 플래닝

### 플랍에서 이미 리버까지 생각하라

초보의 사고: *"플랍에서 탑 페어 맞았으니 베팅하자."*
중급자의 사고: *"탑 페어인데, 이걸로 3스트릿(플랍-턴-리버) 밸류가 나오나?"*

이 질문이 핵심이다. 베팅을 시작하기 전에, **몇 번 베팅할 건지 미리 계획하는 것**이 멀티스트릿 플래닝이다.

### 밸류 스트릿 개수

| 핸드 강도 | 스트릿 수 | 예시 | 전략 |
|----------|----------|------|------|
| 몬스터 | 3스트릿 | 셋, 투페어, 넛 스트레이트 | 플랍-턴-리버 계속 베팅 |
| 강한 핸드 | 2~3스트릿 | 오버페어, TPTK | 보드에 따라 2~3스트릿 |
| 중간 핸드 | 1~2스트릿 | 탑페어 약키커, 미들페어 | 플랍 베팅 → 턴 체크 or 작은 베팅 |
| 약한 핸드 | 0스트릿 | 언더페어, 에어 | 체크 or 1회 블러프 |

### 3스트릿 밸류 테스트

강한 핸드를 잡았을 때, 이 질문을 하자:

> "내가 리버에서 베팅했을 때, 나보다 약한 핸드가 콜할 수 있는가?"

**YES** → 3스트릿 밸류. 플랍부터 계속 베팅.
**MAYBE** → 2스트릿. 플랍-턴 베팅, 리버에서 상황 보고 결정.
**NO** → 1스트릿. 플랍 한 번 베팅하고 이후 체크.

### 실전 예시

**상황**: BTN에서 A♠K♠로 오픈, BB 콜. 플랍: K♥ 8♦ 3♣

**사고 과정**:
1. 나는 TPTK. 강한 핸드다.
2. BB의 콜 레인지에는 Kx(약한 키커), 중간 페어(99-JJ), 드로우가 있다.
3. Kx는 리버까지 콜할 수 있다 → **3스트릿 밸류 가능**.
4. **계획**: 플랍 1/3팟 → 턴 1/2팟 → 리버 2/3팟 (점점 키우기).

**반대 상황**: BTN에서 K♠J♥로 오픈, BB 콜. 플랍: K♥ 8♦ 3♣

**사고 과정**:
1. 나는 탑 페어 약한 키커. 중간 핸드.
2. 리버에서 내 KJ에 콜하는 핸드 = 더 강한 Kx(AK, KQ) → 나한테 불리.
3. 약한 Kx(KT, K9)는 턴까지는 콜하겠지만 리버에서는 접을 수도.
4. **계획**: 플랍 1/3팟 → 턴 상황 보고 (체크 or 작은 베팅) → 리버 체크.
5. 즉, **2스트릿 플랜**.

### 플래닝이 왜 중요한가

계획 없이 "맞았으니까 베팅"만 하면:
- 강한 핸드로 작게 베팅해서 밸류를 못 뽑음
- 중간 핸드로 3스트릿 베팅해서 더 강한 핸드에만 콜 받음
- 블러프를 시작했는데 어디서 멈출지 몰라서 전재산을 태움

계획이 있으면:
- 각 스트릿의 사이즈가 자연스럽게 정해짐
- "이 턴 카드에서 계속 베팅할까?"에 대한 답이 이미 있음
- 블러프도 "어디까지 갈 건지" 미리 정해놓고 시작

## 3. 바렐링

### 더블배럴, 트리플배럴

"배럴(barrel)"은 연속으로 베팅하는 것을 총에 비유한 말이다.
- 1배럴 = 플랍 베팅 (C벳)
- 2배럴 = 플랍 + 턴 베팅 (더블배럴)
- 3배럴 = 플랍 + 턴 + 리버 베팅 (트리플배럴)

### 언제 더블배럴 하나?

플랍에서 C벳한 후, 턴에서 또 베팅할지 결정하는 기준:

#### 밸류 더블배럴
```
✅ 오버페어, TPTK → 턴에서도 밸류 베팅
✅ 탑페어 + 턴 카드가 무해한 경우 (2, 3 같은 로우 카드)
✅ 셋, 투페어 → 당연히 계속 베팅
```

#### 블러프 더블배럴
```
✅ 턴 카드가 "무서운 카드"일 때 → 상대를 접게 만든다
   예: 플랍 8♦ 5♣ 3♠에서 에어로 C벳 → 턴 A♠
   에이스가 떴다 = "나 에이스 가지고 있을 수 있어" 블러프 기회

✅ 드로우가 생겼을 때 → 세미블러프 더블배럴
   예: 플랍에서 에어로 C벳 → 턴에서 플러시 드로우가 생김
   맞으면 이기고, 상대가 접어도 이기는 양방향 베팅

❌ 턴 카드가 상대에게 유리할 때는 체크
   예: 플랍 K♠ 8♦ 3♣에서 C벳 → 턴 J♥
   J는 상대 레인지에 있는 QJ, JT가 맞는 카드 → 블러프 효과 감소
```

### 스케어 카드 (Scare Card)

스케어 카드란 **상대를 겁먹게 만드는 카드**다.

```
최고의 스케어 카드: A (에이스)
  → 거의 모든 레인지에 Ax가 있으므로, 에이스가 뜨면 "맞았을 수 있다"

좋은 스케어 카드: K, Q (하이 카드)
  → 브로드웨이 카드가 뜨면 오프너 레인지에 유리

나쁜 스케어 카드: 7, 6, 5 (로우 카드)
  → 콜러 레인지에 있는 수티드 커넥터가 맞는 카드일 수 있음
```

**블러프 더블배럴의 핵심**: 턴에 스케어 카드가 떨어지면 블러프 기회. 로우 카드가 떨어지면 포기.

### 트리플배럴

리버에서까지 블러프하는 것은 가장 고급 기술이다.

```
트리플배럴 블러프 조건:
1. 내 스토리가 일관적인가? (프리플랍-플랍-턴-리버 전부 말이 되는 라인)
2. 상대가 접을 수 있는 핸드를 가지고 있는가?
3. 리버 카드가 내 블러프 스토리에 유리한가?

실패하는 트리플배럴:
- 상대가 콜링 스테이션일 때 (안 접는다)
- 내 라인이 앞뒤가 안 맞을 때
- 리버 카드가 내 스토리와 맞지 않을 때
```

**초중급 팁**: 트리플배럴 블러프는 아직 자주 하지 않아도 된다. 밸류 트리플배럴(강한 핸드로 3스트릿 베팅)을 먼저 익히자.

## 4. 체크레이즈

### 숨어서 때리기

체크레이즈 = 먼저 체크한 후, 상대가 베팅하면 레이즈하는 것.

**왜 체크레이즈를 하나?**

1. **밸류**: 강한 핸드를 숨겨서 상대 베팅을 유도한 후 레이즈로 팟을 키운다
2. **블러프**: 체크로 약한 척 → 상대 C벳 → 레이즈로 접게 만든다
3. **밸런스**: 체크가 항상 약한 것이 아니라는 걸 보여준다. 안 그러면 상대가 체크에 무조건 베팅

### OOP에서의 체크레이즈

체크레이즈는 주로 **OOP(먼저 행동하는 포지션)**에서 사용한다.

예: BB에서 콜 → 플랍에서 먼저 행동 → 체크 → 상대 C벳 → 레이즈

#### 밸류 체크레이즈 핸드
```
셋 (88 on 8-5-2 보드) → 최고의 체크레이즈 핸드
투페어 (86 on 8-6-3 보드) → 강한 체크레이즈
오버페어 가끔 (웻 보드에서 AA) → 보호 + 밸류
```

#### 블러프 체크레이즈 핸드
```
강한 드로우 (J♥T♥ on 9♥7♥2♣) → 플러시 드로우 + 스트레이트 드로우
거터샷 + 오버카드 (AQ on J-T-5) → 스트레이트 드로우 + 탑페어 가능성
```

### 체크레이즈 사이즈

```
기본: 상대 베팅의 3배

상대가 1/3팟 C벳 → 나는 팟 정도로 체크레이즈
상대가 1/2팟 C벳 → 나는 1.5배 팟으로 체크레이즈
상대가 3/4팟 C벳 → 나는 2-2.5배 팟으로 체크레이즈
```

### 체크레이즈 주의점

```
❌ 드라이 보드에서 에어로 체크레이즈 → 상대 콜하면 턴에서 할 게 없음
❌ 멀티웨이 팟에서 체크레이즈 → 2명 이상을 접게 만들기 어려움
❌ 체크레이즈를 너무 자주 → 상대가 C벳을 안 하기 시작함
```

## 5. 블러프캐칭

### 흔들리지 않는 콜

블러프캐칭이란 **상대가 블러프하고 있다고 판단하고, 중간 강도의 핸드로 콜하는 것**이다.

가장 어려운 스킬 중 하나. 하지만 홈게임에서 돈을 아끼는(또는 따는) 핵심이기도 하다.

### 블러프캐칭 체크리스트

콜할지 폴드할지 고민될 때, 이 4가지를 체크하자:

#### 1. 상대 레인지에 블러프가 충분히 있는가?

```
"이 라인(프리플랍~리버까지의 액션 순서)에서 상대가 블러프할 수 있는 핸드가 뭐가 있지?"

있다 → 블러프캐칭 고려
없다 → 폴드
```

예시:
> 플랍 K♠ 9♥ 7♥에서 상대 C벳 → 턴 2♣에서 더블배럴 → 리버 3♦에서 트리플배럴
> 상대의 블러프 가능성: 플러시 드로우가 미스한 핸드(A♥x♥, Q♥x♥ 등)
> 플러시 드로우가 미스하면 에어가 되니까 블러프할 동기가 있다 → 블러프캐칭 가치 있음

#### 2. 내 핸드가 블러프캐칭에 적합한가?

```
블러프캐칭에 좋은 핸드:
  - 밸류 핸드의 맨 아래쪽 (탑페어 약한 키커, 미들 오버페어)
  - 쇼다운 밸류는 있지만 밸류벳은 못 하는 핸드

블러프캐칭에 안 좋은 핸드:
  - 에어 (콜해서 이길 수가 없음)
  - 아주 강한 핸드 (레이즈해야지 왜 콜만 해)
```

#### 3. 팟 오즈가 맞는가?

```
상대 리버 베팅이 1/2팟 → 25%만 이기면 콜 이득
상대 리버 베팅이 풀팟 → 33%만 이기면 콜 이득

"상대 레인지의 33% 이상이 블러프라고 생각하면 콜."
```

#### 4. 블로커가 있는가?

```
내가 A♥를 들고 있으면 → 상대의 넛 플러시 가능성 차단
내가 J를 들고 있으면 → 상대의 JJ(셋) 가능성 감소

상대의 밸류 핸드를 블로킹하는 카드를 들고 있으면 블러프캐칭에 유리
```

### 홈게임 블러프캐칭 팁

```
상대가 콜링 스테이션이면:
  → 그 사람은 블러프를 잘 안 한다. 큰 베팅에 블러프캐칭 불필요. 접어라.

상대가 어그레시브하면:
  → 블러프 빈도가 높다. 중간 핸드로 콜하는 빈도를 높여라.

"리버에서 큰 베팅을 받았는데 고민이 된다면":
  → 상대의 라인을 처음부터 복기하라.
  → 그 라인에서 밸류 핸드만 있다면 폴드.
  → 미스한 드로우가 충분히 있다면 콜.
```

## 6. 씬밸류벳

### 남들이 못 따는 돈 따기

씬밸류벳(Thin Value Bet)이란 **"겨우 콜 받을 수 있는" 핸드로 베팅하는 것**이다.

이건 중급자가 초보와 차이를 만드는 핵심 기술이다. 초보는 오버페어나 TPTK로만 밸류벳하지만, 중급자는 **미묘한 핸드로도 작은 밸류를 뽑아낸다.**

### 씬밸류벳의 원리

> "내 핸드가 50% 이상의 확률로 콜하는 핸드보다 강하다면, 베팅이 이득이다."

쉽게 말해: 콜 받았을 때 이길 때가 질 때보다 많으면 베팅해야 한다.

### 예시 상황

**상황 1: 리버에서 미들 페어**
> 보드: A♠ 9♦ 5♣ 3♥ 2♠
> 내 핸드: 9♠ 8♠ (미들 페어)
> 상대: BB에서 콜한 패시브 플레이어

```
사고 과정:
- 상대가 Ax를 가지고 있으면 나보다 강하다 → 콜하고 나를 이긴다
- 상대가 포켓 77, 66, 44를 가지고 있으면 나보다 약하다 → 콜할 수 있다
- 상대가 K-high, Q-high를 가지고 있으면 → 대부분 폴드

판단: 콜 받았을 때 이길 때도 질 때도 있다. 50:50 정도.
→ 체크가 안전하다. 씬밸류벳은 조금 더 확실할 때.
```

**상황 2: 리버에서 탑 페어 약한 키커**
> 보드: K♠ 8♦ 5♣ 3♥ 2♠
> 내 핸드: K♥ T♥ (탑 페어)
> 상대: CO에서 콜한 중간 수준 플레이어

```
사고 과정:
- 상대가 Kx 약한 키커(K9, K7)를 가지고 있으면 → 콜하고 내가 이긴다
- 상대가 88, 55를 가지고 있으면 → 나보다 강하지만 레이즈 안 할 수도
- 상대가 AK, KQ를 가지고 있으면 → 나를 이긴다
- 상대가 중간 페어(99, TT)를 가지고 있으면 → 나보다 약하고, 작은 베팅에 콜 가능

판단: 콜 받았을 때 이기는 경우가 더 많다.
→ 1/3팟 씬밸류벳! (큰 사이즈는 약한 핸드만 접게 만들므로 작게)
```

### 씬밸류벳 사이즈

```
핵심: 작게 베팅하라.

왜?
- 큰 베팅 → 강한 핸드만 콜한다 → 대부분 내가 진다
- 작은 베팅 → 약한 핸드도 "이 가격이면 한번 볼까" 하고 콜 → 내가 이긴다

씬밸류벳 사이즈: 1/4 ~ 1/3 팟
```

### 씬밸류벳 vs 체크

```
씬밸류벳이 맞는 상황:
  ✅ 상대가 콜 빈도가 높은 플레이어 (콜링 스테이션)
  ✅ 내 핸드가 콜 받아도 50% 이상 이길 때
  ✅ 상대가 체크레이즈할 가능성이 낮을 때

체크가 나은 상황:
  ❌ 상대가 타이트해서 약한 핸드를 안 콜할 때
  ❌ 콜 받으면 지는 경우가 더 많을 때
  ❌ 상대가 체크레이즈를 자주 하는 플레이어일 때
```

**홈게임 골든 룰**: 홈게임에서는 콜링 스테이션이 많다. 이 사람들 상대로 씬밸류벳은 **금광**이다. 남들이 체크하고 넘어갈 리버에서 1/3팟 베팅 한 번이 장기적으로 수익을 만든다.

## 7. 벳 사이징 심화

### 사이즈에 담긴 메시지

초보 공략집에서는 1/3, 1/2, 3/4로 나눴다. 이제 **왜 그 사이즈인지**를 이해하자.

### 사이즈 선택의 원리

벳 사이즈는 두 가지를 결정한다:
1. **상대가 콜해야 하는 가격** (팟 오즈)
2. **내 레인지의 구성** (어떤 핸드들이 이 사이즈로 베팅하는가)

#### 작은 사이즈 (1/4 ~ 1/3팟)

```
의미: "나는 여러 핸드로 이 사이즈를 쓸 수 있어."
용도:
  - 드라이 보드에서 높은 빈도의 C벳 (맞든 안 맞든)
  - 씬밸류벳
  - "정보 베팅" (상대 반응 보기)

상대 팟 오즈: 매우 좋음 (20-25%) → 많은 핸드가 콜
효과: 상대를 접게 만드는 효과는 약하지만, 넓은 레인지로 쓸 수 있음
```

#### 중간 사이즈 (1/2 ~ 2/3팟)

```
의미: "표준적인 밸류벳 또는 블러프."
용도:
  - 일반적인 밸류벳
  - 일반적인 블러프
  - "모르겠으면 이 사이즈"

상대 팟 오즈: 보통 (25-30%)
효과: 밸런스 잡힌 사이즈. 밸류와 블러프 모두에 적합.
```

#### 큰 사이즈 (3/4팟 ~ 풀팟)

```
의미: "나는 강한 핸드이거나 큰 블러프야."
용도:
  - 웻 보드에서 보호 필요한 밸류벳
  - 드로우에게 비싼 가격 부과
  - 폴라라이즈된 베팅 (매우 강 or 블러프)

상대 팟 오즈: 나쁨 (30-33%) → 드로우 콜이 부담
효과: 약한/중간 핸드를 접게 만듦. 밸류와 블러프의 갭이 큼.
```

#### 오버벳 (팟 이상)

```
의미: "나는 넛(최강)이거나, 너를 접게 만들어야 해."
용도:
  - 넛 핸드로 최대 밸류 (상대가 2nd 넛을 가지고 있을 때)
  - 극단적 블러프 (상대를 매우 어렵게 만들기)
  - 턴/리버에서 SPR(스택 대 팟 비율)이 작을 때

상대 팟 오즈: 매우 나쁨 → 대부분의 핸드가 접어야 함
효과: 가장 강한 압박. 중급자가 배워야 할 무기.
```

### 보드별 사이즈 가이드 (심화)

```
A♠ K♦ 2♣ (에이스 하이, 드라이):
  → 1/3팟 C벳 (높은 빈도). 이 보드는 오프너 레인지에 극도로 유리.
     상대가 뭘 가지고 있든 부담스러운 보드.

Q♥ J♥ 8♠ (하이, 웻):
  → 2/3팟 이상. 드로우가 많아서 보호 필요.
     작게 베팅하면 드로우에게 좋은 가격 제공.

7♠ 5♦ 3♣ (로우, 드라이):
  → 1/3팟 또는 체크 위주. 이 보드는 콜러 레인지에 유리할 수 있음.
     오프너 레인지에 78s, 65s 등이 적음.

K♠ K♦ 5♣ (페어드):
  → 1/3팟 높은 빈도. 상대가 K을 가지기 어려움(2장 중 2장이 보드에).
     대부분의 레인지로 작은 C벳 가능.
```

## 8. 폴라라이즈 vs 머지드

### 베팅 레인지의 두 가지 구성 방식

이건 중급으로 가는 관문이라 할 수 있는 개념이다.

### 머지드 레인지 (Merged)

```
"다양한 강도의 핸드로 베팅"

예: 탑페어, 미들페어, 약한 탑페어, 강한 드로우 모두 같은 사이즈로 베팅
사이즈: 보통 작~중간 (1/3 ~ 1/2팟)

장점: 상대가 내 핸드 강도를 읽기 어려움
단점: 큰 팟을 만들기 어려움

언제 쓰나:
  - 드라이 보드에서 높은 빈도 C벳
  - IP에서 작은 사이즈 베팅
  - 상대가 레인지가 넓고 약할 때
```

### 폴라라이즈드 레인지 (Polarized)

```
"매우 강한 핸드 + 블러프로만 베팅"

예: 셋, 투페어, 오버페어 (밸류) + 미스드 드로우, 에어 (블러프)
    중간 핸드(미들 페어 등)는 체크
사이즈: 보통 큰 사이즈 (3/4팟 ~ 오버벳)

장점: 큰 팟을 만들 수 있음. 강한 핸드로 최대 밸류.
단점: 블러프 비율을 맞춰야 함. 블러프가 너무 많으면 콜 당하고, 적으면 접히기만.

언제 쓰나:
  - 리버에서 마지막 베팅
  - 큰 사이즈 베팅할 때
  - 상대 레인지에 "콜할 수밖에 없는" 중간 핸드가 많을 때
```

### 비유로 이해하기

```
머지드 = 뷔페
  모든 종류의 음식이 조금씩. 가격은 균일. 뭐가 나올지 모름.

폴라라이즈 = 고급 레스토랑 or 편의점
  비싼 스테이크(넛) 아니면 컵라면(블러프).
  중간이 없다. 가격이 극단적.
```

### 실전 적용

```
플랍: 머지드 성향 (작은 사이즈, 넓은 레인지)
턴: 점차 폴라라이즈 (중간 핸드는 체크, 강한/블러프만 베팅)
리버: 완전 폴라라이즈 (넛 or 블러프. 중간은 체크/콜)
```

스트릿이 진행될수록 레인지가 폴라라이즈된다. 이건 자연스러운 흐름이다. 왜냐하면 **스트릿이 갈수록 약한 핸드는 접거나 체크로 빠지고, 강한 핸드와 블러프만 남기 때문**이다.

## 9. 턴 전략

### 가장 어려운 스트릿

많은 사람들이 "플랍이 중요하다"고 하지만, 실제로 **턴이 가장 어려운 의사결정 포인트**다.

이유:
- 팟이 이미 커져 있다 (실수의 비용이 크다)
- 레인지가 좁아져서 상대 핸드 추론이 더 정교해야 한다
- "계속 갈 건가, 여기서 멈출 건가"를 결정해야 한다
- 리버 한 장이 남아서 드로우의 가치가 반으로 줄었다

### 턴 카드 분류

턴에 새 카드가 한 장 깔린다. 이 카드의 성격이 전략을 바꾼다.

#### 브릭 (Brick) — 아무것도 안 바꾸는 카드
```
플랍: K♠ 8♦ 5♣ → 턴: 2♥

2는 거의 아무에게도 도움 안 됨.
보드 텍스쳐가 변하지 않음.
→ 플랍에서의 계획을 그대로 진행.
```

#### 오버카드 — 플랍보다 높은 카드
```
플랍: 9♠ 7♦ 3♣ → 턴: K♥

킹은 상대 레인지에 있는 KQ, KJ, KTs 등을 맞게 만듦.
→ 내가 99(셋)이면 아직 강하다. 계속 베팅.
→ 내가 TT(오버페어)이면 이제 K가 무섭다. 체크 고려.
→ 내가 에어로 블러프 중이었으면 K은 블러프 기회 (스케어 카드).
```

#### 드로우 완성 카드 — 플러시/스트레이트가 완성될 수 있는 카드
```
플랍: T♥ 8♥ 5♣ → 턴: 3♥ (하트 3번째)

플러시가 완성됐을 수 있다!
→ 내가 A♥ 가지고 있으면 넛 플러시. 팟을 키워라.
→ 내가 하트 없는 오버페어면 매우 조심. 체크 or 작은 베팅.
→ 내가 블러프 중이었으면 포기하거나, 하트 블로커가 있으면 블러프 계속.
```

#### 페어링 카드 — 보드에 페어가 생기는 카드
```
플랍: K♠ 9♦ 5♣ → 턴: 9♠

보드에 9 페어.
→ 누군가 트립스(999)를 가지고 있을 가능성.
→ 하지만 9를 가지고 있을 확률은 낮음 (콜러 레인지에 9x가 적으면).
→ 대부분의 경우, 원래 강했던 핸드(KK, AK)가 여전히 강하다.
```

### 턴에서의 핵심 질문

매 턴마다 이 질문을 하자:

> **"이 턴 카드가 내 레인지에 유리한가, 상대 레인지에 유리한가?"**

내 레인지에 유리 → 계속 베팅 (밸류든 블러프든)
상대 레인지에 유리 → 속도를 줄여라 (체크 or 작은 베팅)

## 10. 리버 전략

### 마지막 결정, 가장 큰 돈

리버에서는 더 이상 카드가 나오지 않는다. 모든 드로우가 완성됐거나 실패했다. 핸드의 가치가 확정된 순간이다.

### 리버 베팅의 원칙

#### 밸류벳

```
"상대의 더 약한 핸드가 콜할 수 있는가?"

YES → 밸류벳
NO → 체크

사이즈: 상대가 콜할 수 있는 최대 금액
  - 상대가 탑 페어를 가지고 있을 것 같으면 → 1/2~2/3팟
  - 상대가 2nd 페어를 가지고 있을 것 같으면 → 1/3팟
  - 상대가 미스드 드로우를 가지고 있을 것 같으면 → 체크 (어차피 콜 안 함)
```

#### 블러프

```
"상대의 더 강한 핸드를 접게 만들 수 있는가?"

YES → 블러프
NO → 체크 & 포기

블러프 사이즈: 크게 (2/3팟 이상)
  - 작은 블러프는 상대에게 좋은 팟 오즈를 주므로 콜 당한다.
  - 블러프할 거면 제대로. 안 할 거면 아예 안 하기.
```

#### 체크 (쇼다운)

```
"내 핸드가 베팅하기엔 약하고, 블러프하기엔 쇼다운 밸류가 있는 경우"

예: 미들 페어, 약한 탑 페어
→ 베팅하면 더 강한 핸드만 콜하고 약한 핸드는 폴드
→ 차라리 체크하고 쇼다운 가서 이길 수 있는 만큼 이기자
```

### 리버 콜/폴드 결정

상대가 리버에서 베팅했을 때:

```
Step 1: 상대 레인지를 복기하라
  프리플랍 → 플랍 → 턴 → 리버까지의 라인에서 어떤 핸드가 말이 되는가?

Step 2: 밸류 핸드와 블러프 핸드를 나눠라
  밸류: 이 라인에서 이 사이즈로 베팅할 수 있는 강한 핸드들
  블러프: 미스한 드로우나 에어로 이 라인을 탈 수 있는 핸드들

Step 3: 비율을 어림잡아라
  블러프 비율 > 팟 오즈 → 콜
  블러프 비율 < 팟 오즈 → 폴드
```

### 리버 실전 팁

```
1. "리버에서 큰 베팅 = 강하거나 블러프." 중간이 거의 없다.
   (중간 핸드는 작게 베팅하거나 체크하니까)

2. 리버에서 "레이즈"는 매우 강한 핸드만.
   블러프 레이즈는 고급 기술이므로, 중급에서는 콜 or 폴드 위주로.

3. "상대의 스토리가 말이 되는가?"
   프리플랍-플랍-턴-리버 액션이 일관적인가?
   갑자기 리버에서 큰 베팅이 "앞뒤가 안 맞는" 느낌이면 블러프 가능성 높음.

4. 홈게임에서는 "상대가 리버에서 큰 베팅 = 대부분 강한 핸드."
   라이브 레크리에이셔널 플레이어는 블러프를 생각보다 안 한다.
   의심되면 접는 게 장기적으로 이득.
```

## 11. 멀티웨이 팟

### 3명 이상이면 모든 게 달라진다

온라인에서는 대부분 헤즈업(1:1)이지만, 홈게임에서는 3~5명이 팟에 참여하는 일이 흔하다.

멀티웨이 팟에서의 핵심 변화:

### 레인지 조정

```
헤즈업: 탑 페어면 보통 강하다
3웨이: 탑 페어도 주의해야 한다 (누군가 투페어 이상일 수 있음)
4웨이+: 탑 페어는 약하다. 투페어 이상을 노려야 한다.

원칙: 사람이 많아질수록, 이기기 위해 필요한 핸드 강도가 올라간다.
```

### 블러프 효과 감소

```
헤즈업: 1명을 접게 하면 됨 → 블러프 성공률 높음
3웨이: 2명을 접게 해야 함 → 블러프 성공률 대폭 감소
4웨이: 3명을 접게 해야 함 → 블러프 거의 불가능

핵심: 멀티웨이에서 블러프를 줄이고 밸류벳을 늘려라.
```

### C벳 조정

```
헤즈업에서 C벳 빈도: 60~80%
3웨이에서 C벳 빈도: 30~40%
4웨이에서 C벳 빈도: 15~25% (진짜 강할 때만)

멀티웨이에서 에어로 C벳하면 누군가는 콜한다.
강한 핸드로만 베팅하고, 약하면 체크하라.
```

### 포지션 가치 증가

```
멀티웨이에서 IP(마지막 행동)의 가치가 더 커진다.
이유: 앞 사람들의 액션을 전부 보고 결정할 수 있다.

BTN에서 멀티웨이 팟 → 최고의 상황
얼리 포지션에서 멀티웨이 → 타이트하게, 밸류 위주
```

### 멀티웨이 핵심 요약

```
1. 블러프를 줄여라 → 밸류벳 위주
2. 핸드 강도 기준을 올려라 → 탑 페어로 안심하지 마라
3. 드로우는 더 가치 있다 → 멀티웨이에서 팟이 크므로 임플라이드 오즈가 좋다
4. 포지션 사수 → IP에서만 넓게 참여
```

## 12. GTO vs 익스플로잇

### 두 개의 칼

포커 전략에는 두 가지 철학이 있다.

### GTO (Game Theory Optimal)

```
정의: 상대가 뭘 하든 장기적으로 손해 보지 않는 전략

비유: 가위바위보를 33:33:33으로 무작위로 내는 것.
     상대가 어떤 패턴을 쓰든 나는 장기적으로 손해가 없다.

장점:
  - 어떤 상대를 만나도 크게 지지 않는다
  - "정답"이 있어서 공부하기 좋다
  - 실수가 적다

단점:
  - 상대의 약점을 공략하지 않는다
  - 약한 상대를 만나도 최대 이득을 못 뽑는다
  - 완벽한 GTO는 인간이 구현 불가능 (컴퓨터나 가능)
```

### 익스플로잇 (Exploitative)

```
정의: 상대의 약점을 파악하고, 그에 맞게 전략을 편향시키는 것

비유: 상대가 바위를 70% 낸다는 걸 알면, 나는 보를 많이 내는 것.
     상대의 패턴을 이용한다.

장점:
  - 약한 상대에게서 최대 이득을 뽑는다
  - 홈게임/펍에서 가장 효과적인 전략
  - 관찰력 + 적응력으로 승리

단점:
  - 상대를 잘못 읽으면 역으로 당한다
  - 상대가 적응하면 효과 감소
  - 강한 상대에게는 통하지 않을 수 있음
```

### 홈게임에서의 적용

```
기본은 GTO에 가깝게 + 약점이 보이면 익스플로잇

구체적으로:

1단계: GTO 기반 프레임워크 (이 공략집의 RFI, 3벳, C벳 전략)
  → 기본 뼈대를 잡는다

2단계: 상대 관찰 (30분)
  → 각 플레이어의 유형 파악

3단계: 익스플로잇 조정
  → 콜링 스테이션에게 블러프 제거, 밸류벳 추가
  → 타이트한 상대에게 스틸 추가
  → 어그레시브한 상대에게 트랩 추가
```

### 흔한 익스플로잇 레시피

| 상대의 약점 | 익스플로잇 방법 |
|------------|---------------|
| 너무 많은 핸드 참여 (루즈) | 밸류벳 레인지를 넓혀라. 탑 페어 약키커로도 큰 밸류. |
| 너무 적은 핸드 참여 (타이트) | 블라인드 스틸을 많이 해라. 그가 참여하면 존중하고 폴드. |
| 거의 폴드 안 함 (콜링 스테이션) | 블러프 제거. 밸류벳만. 작은 핸드로도 밸류. |
| 3벳을 잘 안 함 | 오픈 레인지를 넓혀라. 값싸게 팟 참여. |
| C벳에 거의 폴드 | C벳 빈도를 90%로 올려라. 에어로도 베팅. |
| C벳에 거의 콜 | C벳 빈도를 줄이고, 밸류 위주로만 베팅. |
| 리버 블러프가 없음 | 리버에서 약한 핸드로 블러프캐칭 안 해도 됨. 그가 베팅하면 접어라. |
| 리버 블러프가 많음 | 중간 핸드로 콜 빈도를 올려라. |

## 13. 라이브 리딩 심화

### 베팅 패턴으로 읽기

초보 공략집에서 "텔(tell)"을 다뤘다. 중급에서는 **베팅 패턴**에 집중한다. 몸짓보다 훨씬 정확하다.

### 타이밍 텔

```
빠른 콜 (Snap Call):
  → 보통 드로우 or 중간 핸드
  → 진짜 강하면 레이즈를 고민하느라 시간이 걸린다
  → 진짜 약하면 폴드를 고민하느라 시간이 걸린다
  → "고민 없이 바로 콜" = 중간 어딘가

느린 콜 (Tank Call):
  → 경계선 핸드. 폴드와 콜 사이에서 고민.
  → 상대의 블러프캐칭일 가능성.

빠른 체크:
  → 약한 핸드일 가능성 높음
  → "관심 없다"는 신호

느린 체크 후 콜:
  → 체크레이즈를 고민했을 수 있음 → 중간~강한 핸드
```

### 베팅 사이즈 패턴

```
상대가 평소보다 큰 베팅:
  → 초보일수록 "강하면 크게, 약하면 작게" 경향
  → 하지만 숙련자는 반대로 쓸 수도
  → 상대의 과거 패턴을 참고

상대가 "어정쩡한" 사이즈 (팟의 40%? 57%?):
  → 보통 밸류벳. 사이즈를 고민한 흔적.
  → 블러프는 보통 깔끔한 사이즈 (1/2, 2/3, 풀팟)

올인 (실수로 너무 큰 베팅):
  → 라이브에서 "올인 오버벳"은 보통 넛에 가까운 핸드
  → 또는 완전 초보가 폴드 유도 시도
```

### 프리플랍 사이즈 텔

```
상대가 평소 3BB 오픈인데 갑자기 5BB 오픈:
  → 라이브 레크 플레이어: 대부분 프리미엄 핸드 (AA, KK)
  → "콜 받고 싶은데 크게 올린다" = 역설적으로 강한 핸드

상대가 림프 후 누군가 레이즈하자 리림프(콜):
  → 보통 포켓 페어(셋 마이닝) or 수티드 커넥터
  → 강한 핸드면 처음부터 레이즈했을 것

상대가 림프 후 레이즈하자 리레이즈(림프 레이즈):
  → 거의 항상 AA or KK. 트랩이다. 도망쳐라.
```

### 포지션별 베팅 패턴

```
상대가 OOP에서 체크 → 콜 → 체크 → 콜:
  → 보통 중간 핸드. 체크/콜 라인은 "쇼다운 밸류는 있지만 공격은 못 하는" 핸드.
  → 리버에서 밸류벳 기회.

상대가 OOP에서 체크 → 체크 → 갑자기 동크 벳(선 베팅):
  → "함정이었다" 가능성 (슬로우플레이 후 공격)
  → 또는 "체크 2번 했더니 프리 카드를 줘서 드로우가 완성됨"
  → 주의 필요.

상대가 IP에서 플랍 체크 → 턴 베팅:
  → "딜레이드 C벳". 플랍에서 체크하고 턴에서 공격.
  → 상대의 체크를 약한 신호로 읽고 블러프하는 것일 수 있음.
  → 또는 플랍에서 팟 컨트롤하다가 턴에서 밸류.
```

## 14. 세션 리뷰

### 성장의 엔진

실력이 느는 사람과 제자리인 사람의 차이: **복기를 하느냐 안 하느냐.**

### 세션 리뷰 방법

#### 1. 핸드 3개만 기록하라

매 세션 끝나면, **가장 어려웠던 3개 핸드**만 기록한다.

```
기록 형식:

핸드 #1
- 상황: CO 오픈, BTN 콜
- 내 핸드: A♠Q♥
- 보드: Q♦ 9♥ 5♣ | 3♠ | K♥
- 액션: C벳 1/2팟 → 턴 체크 → 리버 상대 2/3팟 베팅 → 콜
- 결과: 상대 K9s로 투페어. 나 패배.
- 반성: 턴 체크 자체는 맞았지만, 리버 K가 상대 레인지에 유리. 폴드가 나았을 수도.
```

매번 이렇게 완벽하게 적을 필요는 없다. **핵심만 짧게.** 안 쓰는 것보다 대충이라도 쓰는 게 100배 낫다.

#### 2. 질문 3개

매 핸드 복기 시 이 3가지를 물어보자:

```
Q1: "나의 결정은 올바랐나?"
  → 결과와 무관하게. 졌어도 올바른 결정이었으면 OK.

Q2: "상대의 레인지를 제대로 읽었나?"
  → 상대의 프리플랍-플랍-턴 액션을 보고 레인지를 좁혔는가?

Q3: "다시 이 상황이 오면 어떻게 할까?"
  → 같은 선택? 다른 선택? 왜?
```

#### 3. 패턴 찾기

10세션 정도 기록하면 패턴이 보인다:

```
"나는 리버에서 블러프캐칭을 너무 많이 한다"
"나는 웻 보드에서 C벳을 너무 많이 한다"
"나는 3벳 팟에서 포스트플랍이 약하다"
"나는 특정 상대에게 유독 많이 진다"
```

이 패턴을 발견하는 것 자체가 실력 향상이다.

## 15. 중급 실전 체크리스트

### 게임 중 사고 루틴

매 핸드마다 이 순서로 생각:

```
프리플랍:
  1. 내 포지션 확인
  2. 앞 사람들의 액션 확인
  3. 내 핸드가 레인지에 있는가?
  4. 레이즈/콜/폴드 결정

플랍:
  1. 보드 텍스쳐 (드라이/웻/모노톤/페어드) — 3초
  2. 내 핸드 강도 평가 (오버페어~에어)
  3. 상대 레인지 추정 (프리플랍 액션 기반)
  4. 멀티스트릿 플랜 (몇 스트릿 밸류?)
  5. 베팅/체크 + 사이즈 결정

턴:
  1. 턴 카드가 누구에게 유리한가?
  2. 상대 레인지를 플랍 액션으로 좁히기
  3. 계획 수정 or 유지
  4. 베팅/체크 결정

리버:
  1. 드로우 완성 여부 확인
  2. 상대 레인지 최종 좁히기
  3. 밸류벳 / 블러프 / 체크 / 콜 / 폴드 결정
  4. "상대의 스토리가 말이 되는가?"
```

### 중급자가 빠지기 쉬운 함정 TOP 5

| 순위 | 함정 | 해결 |
|------|------|------|
| 1 | "난 이제 잘 하니까" 자만 | 겸손하게. 항상 배울 것이 있다. |
| 2 | 화려한 블러프에 집착 | 화려함보다 수익성. 밸류벳이 돈을 번다. |
| 3 | 모든 상대를 GTO로 대응 | 홈게임에서는 익스플로잇이 더 효과적. |
| 4 | 라인을 고민 안 하고 자동 조종 | 매 핸드 의식적으로 사고 루틴을 돌려라. |
| 5 | 세션 리뷰를 안 함 | 10분만 투자해라. 성장의 90%는 여기서 온다. |
